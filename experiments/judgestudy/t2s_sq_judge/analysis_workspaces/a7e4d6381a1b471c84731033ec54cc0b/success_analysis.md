# Success Memory Item 1
## Title
Verbatim Snippet Matching for Trivia-Style Prompts
## Description
Rapidly resolve highly specific or colloquially phrased questions by locating exact textual overlaps in retrieved context rather than relying solely on semantic relevance.
## Content
When a prompt mimics trivia clues, quiz bowls, or forum queries, scan retrieved document paragraphs for verbatim matches of the question's distinctive phrasing. User-generated content and trivia archives frequently embed the complete question-answer pair within a single snippet. Identify the term immediately following the matched string, confirm it aligns with the query's core concept, and output it using the required formatting tags.
