# Success Memory Item 1
## Title
Cross-Reference Shared Actions with Cast Lists
## Description
Match specific plot actions or scenarios from the query against retrieved text to identify which named individuals are explicitly grouped together performing that action.
## Content
When a question provides one participant and a specific shared event, scan the context for sentences that pair the known entity with potential candidates executing that exact event. Prioritize explicit textual links over general cast mentions to isolate the correct counterpart.

# Success Memory Item 2
## Title
Filter Candidates by Narrative Role Alignment
## Description
Distinguish between relevant co-participants and peripheral cast members by verifying alignment with the precise character description or functional role stated in the prompt.
## Content
Verify that any candidate name found in the context actually fulfills the specific narrative function or occupation described. Discard names that appear in the broader cast list but do not participate in the queried scenario.

# Success Memory Item 3
## Title
Strict Output Formatting
## Description
Isolate the final identified entity and place it directly inside the required tags, omitting all intermediate reasoning or conversational filler.
## Content
Once the correct entity is confirmed through contextual cross-referencing, extract only the precise name or phrase requested. Ensure the final output contains solely the answer enclosed in the specified tags, adhering strictly to length and formatting constraints.
