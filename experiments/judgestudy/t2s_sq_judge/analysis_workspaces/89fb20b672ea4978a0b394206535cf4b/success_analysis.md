# Success Memory Item 1
## Title
Decode Descriptive Trivia Clues
## Description
Treat prompts structured as standalone statements or quotes as direct requests to identify the subject entity based on its defining attributes.
## Content
When a prompt lacks a direct interrogative structure, extract the core comparative or superlative attribute and map it to the most prominent historical or cultural entity known for that trait. Focus on resolving the implied "what/who" behind the descriptive statement rather than treating it as a literal query.

# Success Memory Item 2
## Title
Locate Prompt Phrases in Retrieved Snippets
## Description
Prioritize scanning retrieved documents for exact or near-exact matches of the prompt's wording to quickly establish context and source type.
## Content
Before generating an answer, search the provided context for verbatim or highly similar phrasing from the prompt. Identifying the source format (e.g., game show archive, encyclopedia entry, historical summary) immediately narrows the domain and validates the expected answer style without requiring additional tool calls.

# Success Memory Item 3
## Title
Leverage Comparative Superlatives for Entity Resolution
## Description
Use extreme comparative language in the prompt as a primary filter to resolve ambiguity between similar entities.
## Content
When multiple candidates could fit a prompt, prioritize the one explicitly associated with the prompt's extreme comparison. This heuristic efficiently bypasses less relevant options and targets the canonical answer recognized in historical or popular discourse.
