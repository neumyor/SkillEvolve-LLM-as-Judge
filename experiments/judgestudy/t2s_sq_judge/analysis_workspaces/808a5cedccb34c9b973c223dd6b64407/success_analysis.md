# Success Memory Item 1
## Title
Exact Phrase Matching for Entity Completion
## Description
Resolve incomplete titles or names by locating their full counterparts in the context through keyword anchoring.
## Content
When presented with a partial entity name or phrase, scan the retrieved documents for exact or near-exact matches containing the provided keywords. Extract the missing segment directly from the confirmed full name to complete the query accurately.

# Success Memory Item 2
## Title
Direct Lexical Extraction for Structured Prompts
## Description
Prioritize literal text retrieval over inference when answering fill-in-the-blank or trivia-style questions.
## Content
Identify the complete official designation in the source material and isolate only the missing term(s) that fit the syntactic structure of the prompt. Ensure the final output strictly occupies the blank position without adding explanatory text or deviating from the requested format.
