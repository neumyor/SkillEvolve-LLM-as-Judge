# Success Memory Item 1
## Title
Exact Phrase Matching for Trivia-Style Queries
## Description
Leverage exact string overlap between the prompt and retrieved snippets to quickly resolve trivia or historical factoid questions.
## Content
Questions phrased as specific historical clues or quiz prompts often appear verbatim in retrieved datasets or archives. Scan the context for exact matches to the question's unique phrasing or key identifiers. When found, extract the answer directly from the same passage, as these sources are typically structured to present the clue and its corresponding answer side-by-side. This avoids unnecessary synthesis and capitalizes on high-confidence direct retrieval.
