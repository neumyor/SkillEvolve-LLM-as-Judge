# Success Memory Item 1
## Title
Multi-Constraint Entity Mapping
## Description
Systematically align each explicit question constraint with retrieved context to isolate the correct target entity.
## Content
When answering entity identification queries containing multiple specific attributes (e.g., actor, role, network, source material), scan retrieved documents to find the single entry that satisfies every stated condition simultaneously. Discard partial matches or related entries that share only one or two attributes to prevent confusion between similar titles, remakes, or franchise spin-offs.

# Success Memory Item 2
## Title
Multi-Source Corroboration
## Description
Leverage multiple independent context snippets to corroborate the same factual claim before finalizing an answer.
## Content
Relying on a single document can sometimes lead to misinterpretation due to truncated text or contextual ambiguity. Actively compare findings across several retrieved sources; when multiple independent snippets converge on the identical title or fact, proceed with high confidence. This cross-referencing step ensures accuracy before committing to a final output.

# Success Memory Item 3
## Title
Exact String Extraction & Formatting
## Description
Preserve the original naming convention from the context and apply strict output formatting without paraphrasing.
## Content
For direct factual questions, avoid rephrasing or adding descriptive qualifiers to the target name. Extract the exact title or identifier as it appears in the confirmed context. Immediately wrap the extracted string in the required tags to ensure compliance with parsing requirements and maximize exact match scores.
