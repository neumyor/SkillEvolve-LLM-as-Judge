# Success Memory Item 1
## Title
Infer Missing Components in Fragmented Prompts
## Description
Recognize when a user query is phrased as an incomplete sentence or trivia-style clue, and deduce the specific missing element being asked for.
## Content
Parse the prompt to identify implied blanks or referential phrases like "this way," then treat them as direct questions seeking the missing variable rather than literal statements requiring elaboration.

# Success Memory Item 2
## Title
Map Ambiguous References to Explicit Contextual Phrases
## Description
Align vague or shorthand references in the prompt with clear, repeated terminology found across multiple retrieved documents to pinpoint the exact answer.
## Content
Scan context snippets for recurring keywords or idiomatic expressions that directly correspond to the prompt's framing, prioritizing exact matches over paraphrased interpretations to maintain accuracy.

# Success Memory Item 3
## Title
Extract Minimal Core Answers for Strict Formatting
## Description
Condense the identified solution to its most essential word or short phrase, stripping away explanatory context to meet rigid output constraints.
## Content
After locating the correct term, isolate only the precise lexical unit requested, ensuring it stands alone within the required tags without additional commentary or structural padding.
