# Success Memory Item 1
## Title
Enumerate Complete Sequences Before Calculation
## Description
Explicitly list the full ordered set of items referenced in the query to establish a clear baseline for positional reasoning.
## Content
When addressing questions about relative positioning, advancement, or steps within a structured system, first extract and write out the entire sequence in its correct order. This creates a reliable reference frame and minimizes cognitive load during subsequent counting operations.

# Success Memory Item 2
## Title
Execute Incremental Positional Mapping
## Description
Translate abstract numerical offsets into concrete sequential steps by walking through the enumerated list one item at a time.
## Content
For prompts specifying movement along a hierarchy (e.g., "advance X levels from Y"), do not rely on direct subtraction or addition. Instead, traverse the list step-by-step from the starting point, explicitly labeling each intermediate stage. This ensures accurate mapping and makes the logical progression transparent.

# Success Memory Item 3
## Title
Ground Derived Results in Source Material
## Description
Align the calculated outcome with the retrieved context to confirm consistency and maintain factual grounding.
## Content
After determining the target position, cross-check the extracted sequence and final result against the provided documents. Ensure that the terminology, ordering, and boundaries match the source text exactly before synthesizing the final response.
