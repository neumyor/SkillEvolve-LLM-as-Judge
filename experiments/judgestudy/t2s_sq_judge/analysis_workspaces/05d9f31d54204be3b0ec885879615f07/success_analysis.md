# Success Memory Item 1
## Title
Decompose Compound Trivia Clues
## Description
Isolate distinct semantic components within multi-reference queries to identify a unifying answer.
## Content
When a prompt presents multiple seemingly unrelated hints, treat each as an independent constraint. Map each hint to its corresponding domain knowledge, then locate the single term or phrase that satisfies all constraints simultaneously. This reduces ambiguity and accelerates convergence on the correct answer.

# Success Memory Item 2
## Title
Leverage Cross-Domain Lexical Intersection
## Description
Use overlapping terminology across different knowledge domains to validate candidate answers.
## Content
In stylized questions like crossword clues or trivia prompts, answers often bridge disparate fields. Generate candidate terms from one hint and verify their applicability to the other hint(s). Prioritize responses where the candidate word forms a recognized compound, title, or standard definition across all mentioned contexts, ensuring high confidence without exhaustive searching.

# Success Memory Item 3
## Title
Match Query Structure to Retrieval Strategy
## Description
Adapt information gathering based on recognizable question formats.
## Content
Recognize structural markers of specific query types (e.g., "A or B", quoted titles, fill-in-the-blank patterns). Shift focus from broad explanation to exact-match retrieval, prioritizing sources that explicitly list clues, definitions, or trivia databases. This alignment prevents overcomplication and targets the precise lexical gap the query intends to fill.
