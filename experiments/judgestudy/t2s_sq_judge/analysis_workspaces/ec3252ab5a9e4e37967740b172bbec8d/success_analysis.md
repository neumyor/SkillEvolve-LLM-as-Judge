# Success Memory Item 1
## Title
Pop-Culture Trivia Resolution via Entity Cross-Referencing
## Description
Systematically link specific character, actor, or media references in trivia prompts to their source franchise using retrieved contextual anchors.
## Content
Extract unique identifiers from the question (e.g., actor names, character roles, associated songs/videos) and scan retrieved documents for direct matches or explicit connections. Use these contextual anchors to resolve indirect clues into a precise target entity. Ensure the final output matches the requested scope (e.g., series vs. individual installment) and strictly applies the mandated formatting tags without extra commentary.
