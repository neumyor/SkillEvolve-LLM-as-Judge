# Success Memory Item 1
## Title
Targeted Keyword Retrieval and Explicit Statement Identification
## Description
Scan retrieved documents for exact matches of core question terms and prioritize sentences containing direct action verbs that establish clear relationships between entities.
## Content
When answering factual questions, isolate key identifiers from the prompt and search the context for verbatim mentions. Extract answers directly from unambiguous declarative statements that link the identified entities, avoiding inference when explicit textual evidence is present.

# Success Memory Item 2
## Title
Direct Entity Association Mapping
## Description
Map specific question components to contextual phrases describing ownership, founding, or curation to pinpoint the target entity.
## Content
Decompose the query into its constituent parts and align each with corresponding details in the text. Use relational cues such as "her gallery," "opened by," or "organized by" to quickly isolate the responsible individual or organization without cross-referencing unrelated information.

# Success Memory Item 3
## Title
Structured Execution and Format Compliance
## Description
Follow a rigid stepwise workflow: parse intent, locate evidence, isolate answer, align with constraints, and apply exact output formatting.
## Content
Maintain a systematic approach by explicitly stating each processing stage. Before generating the final response, confirm that the extracted answer precisely matches the required structural markers to ensure compliance and prevent formatting errors.
