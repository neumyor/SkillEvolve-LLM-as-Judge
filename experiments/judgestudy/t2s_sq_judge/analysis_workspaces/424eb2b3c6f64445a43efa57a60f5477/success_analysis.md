# Success Memory Item 1
## Title
Thematic Keyword Extraction & Candidate Generation
## Description
Translate descriptive or trivia-style prompts into core concepts to scan retrieved documents for overlapping terminology and potential answer candidates.
## Content
Break down the query into key themes (e.g., medical innovations, historical figures, specific outcomes) and systematically search the context for documents containing matching terms or related ideas to narrow down possible entities.

# Success Memory Item 2
## Title
Direct Textual Evidence Matching
## Description
Establish answer confidence by confirming that the context explicitly links the candidate entity to the exact claims, achievements, or phrasing presented in the prompt.
## Content
Before finalizing an answer, ensure the retrieved text contains a clear, unambiguous connection between the candidate and the query's specific details, prioritizing explicit mentions over inferred associations.
