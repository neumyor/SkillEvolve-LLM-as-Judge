# Success Memory Item 1
## Title
Targeted Keyword Mapping
## Description
Scan retrieved context for distinctive prompt phrases to rapidly locate candidate answers.
## Content
For descriptive or trivia-style queries, treat unique identifiers (nicknames, textures, common uses) as search anchors. Prioritize passages where these exact or closely related terms appear together, as they typically contain the direct answer.

# Success Memory Item 2
## Title
Cross-Snippet Consensus
## Description
Validate the initial find by checking if multiple independent context segments point to the same entity.
## Content
Avoid relying on a single document snippet. Actively scan for additional references that pair the prompt's descriptors with the same target term. Converging mentions across different sources strongly indicate the correct extraction and reduce ambiguity.

# Success Memory Item 3
## Title
Precise Tagged Extraction
## Description
Isolate the exact answer term and format it strictly within the required output tags.
## Content
Once the target entity is confirmed, strip away surrounding context, synonyms, or explanatory text. Output only the precise noun or phrase requested, wrapped exactly in the specified delimiters to satisfy structural constraints.
