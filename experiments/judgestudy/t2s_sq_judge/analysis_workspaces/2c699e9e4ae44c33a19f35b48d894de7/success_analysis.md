# Success Memory Item 1
## Title
Direct Query-to-Snippet Mapping
## Description
Align query components with highly structured or explicit source snippets to rapidly isolate candidate answers.
## Content
Decompose the question into key entities, timeframes, and actions. Scan retrieved documents for exact phrase matches or rigidly formatted snippets that mirror the query structure. Prioritize passages where the answer is explicitly stated in proximity to the queried terms.

# Success Memory Item 2
## Title
Cross-Document Thematic Alignment
## Description
Confirm candidate answers by checking for consistent contextual signals across multiple retrieved segments.
## Content
After locating a direct match, examine neighboring documents for shared entities, historical periods, or subject matter. If multiple sources independently point to the same conclusion through overlapping details, treat the convergence as sufficient grounds for selection.

# Success Memory Item 3
## Title
Constraint-First Output Generation
## Description
Map selected answers directly to required structural templates without supplementary text.
## Content
Once the answer is identified, immediately apply the specified formatting rules. Omit reasoning traces, explanations, or conversational filler in the final response to ensure strict compliance with output constraints.
