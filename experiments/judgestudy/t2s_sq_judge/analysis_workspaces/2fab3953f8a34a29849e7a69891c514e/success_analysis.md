# Success Memory Item 1
## Title
Direct Definition Mapping
## Description
Translate descriptive or clue-based prompts into precise terminology by locating explicit definitions in the context.
## Content
When a prompt uses descriptive language, quotes, or trivia-style phrasing to define a concept, search the context for sentences that explicitly define the described attributes. Match the prompt's key descriptors to the exact term used in those definitional statements to resolve the intended answer.

# Success Memory Item 2
## Title
Phrasal Overlap Detection
## Description
Identify the target answer by cross-referencing unique phrasing from the prompt with overlapping vocabulary in the retrieved documents.
## Content
For fill-in-the-blank, quote, or riddle-style questions, scan the context for documents containing the prompt's distinctive keywords or structural patterns. Prioritize passages where the prompt's phrasing closely mirrors the document's wording or directly addresses the described scenario, as high lexical overlap often indicates the correct referent.

# Success Memory Item 3
## Title
Semantic Equivalence Resolution
## Description
Resolve prompts using indirect or colloquial descriptions by identifying their standard equivalents in the context.
## Content
If a prompt uses informal, historical, or circumstantial language to describe a subject, locate the formal or common term within the context that shares identical functional or categorical properties. Use contextual usage markers (e.g., sales channels, processing states, or regulatory labels) to confirm the equivalence before finalizing the response.
