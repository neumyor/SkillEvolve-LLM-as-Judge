# Success Memory Item 1
## Title
Direct Definition Mapping
## Description
Align prompt phrasing with retrieved document snippets to locate and extract defined terms.
## Content
When answering definition-based or trivia questions, scan context snippets for sentences that structurally mirror the prompt's conditions. Identify the passage that explicitly equates a descriptive phrase to a specific label, then extract that label as the final answer. Prioritize glossary-style or dictionary-format entries, as they typically contain direct, unambiguous mappings.

# Success Memory Item 2
## Title
Semantic Component Matching
## Description
Resolve wording variations by focusing on conceptual equivalence rather than requiring verbatim text matches.
## Content
Questions frequently rephrase standard definitions using synonyms or altered syntax. Map core semantic components (e.g., labor duration, output capacity, or operational scope) across the prompt and context. Once conceptual alignment is confirmed, extract the associated technical term without waiting for exact string matches, ensuring robustness against paraphrasing.
