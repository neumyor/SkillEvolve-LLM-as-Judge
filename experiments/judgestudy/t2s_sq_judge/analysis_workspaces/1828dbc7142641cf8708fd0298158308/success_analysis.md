# Success Memory Item 1
## Title
Decode Implicit Subjects in Statement-Style Prompts
## Description
When a prompt is phrased as a quote or observation rather than a direct question, identify the underlying entity being referenced through contextual clues.
## Content
Treat declarative or quoted prompts as implicit requests for the primary subject. Extract key descriptors (e.g., familial relations, inventions, associated works) from the prompt and use them to locate the target entity within the retrieved context.

# Success Memory Item 2
## Title
Cross-Reference Descriptive Clues Across Multiple Documents
## Description
Verify entity identity by correlating specific attributes mentioned in the prompt with consistent details across several context snippets.
## Content
Scan all provided documents for overlapping mentions of the prompt's unique identifiers. Confirm the target entity only when multiple independent sources consistently link the same set of attributes to one name.

# Success Memory Item 3
## Title
Resolve Name Variants Using Contextual Hierarchy
## Description
When context contains multiple name formats or related individuals, select the variant that best aligns with the prompt's focus and standard naming conventions.
## Content
Distinguish between the target entity and closely related figures by prioritizing the name most directly associated with the prompt's core identifiers. Use full, standardized names when available to ensure precision.
