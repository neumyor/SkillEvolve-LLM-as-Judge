# Success Memory Item 1
## Title
Extract Parenthetical Translations from Reference Titles
## Description
When queried for the English meaning or translation of a non-English title or phrase, prioritize extracting the parenthetical equivalent found in source metadata or article headers.
## Content
Reference documents frequently format bilingual terms as `Original Phrase (English Equivalent)`. Locate the target phrase in the context, identify the immediately following parenthetical text, and use it as the direct answer. Confirm alignment with the query's semantic intent before finalizing.
