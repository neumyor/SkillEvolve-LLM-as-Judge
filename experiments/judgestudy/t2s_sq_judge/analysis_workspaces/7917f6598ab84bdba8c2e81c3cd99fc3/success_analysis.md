# Success Memory Item 1
## Title
Map Query Descriptors to Definitional Links
## Description
Translate open-ended or fill-in-the-blank prompts into explicit entity-attribute relationships to guide targeted context scanning.
## Content
Identify the core relationship requested by the question (e.g., "X are the serfs of Y") and search the context for direct definitional statements that pair the given attribute with a specific proper noun. Prioritize encyclopedic or authoritative phrasing that establishes a clear, unambiguous association between the clue and the target entity.

# Success Memory Item 2
## Title
Cross-Reference Contextual Consensus
## Description
Strengthen answer confidence by verifying that multiple independent context passages converge on the same candidate.
## Content
Avoid over-relying on a single snippet. Actively scan several retrieved documents to see if they independently point to the identical entity. When multiple sources consistently link the query's clues to the same subject, treat that convergence as sufficient grounds for selection without requiring additional searches.

# Success Memory Item 3
## Title
Enforce Strict Format with Minimal Output
## Description
Deliver only the exact target identifier wrapped in the required tags, stripping away all explanatory or contextual text.
## Content
Once the correct entity is isolated, remove surrounding descriptions, synonyms, or qualifying phrases. Output solely the precise name or term requested, enclosed strictly within the designated answer tags to align with automated parsing requirements and prevent formatting penalties.
