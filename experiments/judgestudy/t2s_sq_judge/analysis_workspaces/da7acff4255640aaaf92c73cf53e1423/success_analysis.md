# Success Memory Item 1
## Title
Contextual Keyword Alignment and Consensus Extraction
## Description
For factual retrieval tasks, locate the core entity in the prompt, trace its explicit definition or alias within the provided text, and ensure consistency by checking for identical terminology across multiple retrieved passages.
## Content
- Isolate the key phrase or subject from the question.
- Scan the retrieved context for direct statements that define or rename the target entity.
- Cross-reference multiple passages to confirm the terminology is consistently applied rather than isolated to a single source.
- Extract the exact term stated in the context as the final answer, adhering strictly to formatting requirements.
