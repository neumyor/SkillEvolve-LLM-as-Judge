# Success Memory Item 1
## Title
Superlative-to-Entity Mapping
## Description
Align prompt descriptors with explicit evaluative claims in the context to isolate the target subject.
## Content
When a question cites a specific ranking, accolade, or qualitative label, scan the retrieved passages for matching superlatives or definitive statements. Extract the noun phrase directly attached to the claim to identify the correct work, prioritizing exact phrasing matches over inferred associations.

# Success Memory Item 2
## Title
Canonical Title Normalization
## Description
Resolve abbreviated, historical, or variant names in the prompt to their standard, widely recognized titles using contextual frequency.
## Content
Prompts frequently use shortened references or legacy naming conventions. Identify the full, commonly accepted title by tracking which name appears most consistently across multiple context snippets. Select the most complete and frequently cited form for the final output to ensure precision and alignment with standard references.

# Success Memory Item 3
## Title
Cross-Passage Consistency Filtering
## Description
Confirm a candidate answer by verifying that multiple independent context snippets attribute the same status or description to it.
## Content
Avoid relying on isolated excerpts that may lack full context. Cross-reference several retrieved documents to check if they independently highlight the same work with similar praise or classification. Strong thematic convergence across passages reliably indicates the correct answer and filters out tangential or misaligned mentions.
