# Success Memory Item 1
## Title
Etymological Clue Mapping
## Description
Match linguistic or historical clues in the prompt directly to definitional statements in the retrieved context.
## Content
When a question provides an origin word, translation, or historical reference, scan the context for explicit etymological links or definitions that connect the clue to the target term. Prioritize passages that use direct attribution phrasing (e.g., "comes from," "derived from," "means") to establish the relationship.

# Success Memory Item 2
## Title
Direct Term Selection
## Description
Select the most concise and structurally aligned term when multiple valid variants exist in the context.
## Content
If the context offers synonymous or compound variations (e.g., base term vs. modified phrase), choose the simplest form that directly answers the prompt's grammatical structure. Avoid adding unnecessary modifiers unless the question explicitly requests the full technical designation.

# Success Memory Item 3
## Title
Strict Answer Tagging
## Description
Enclose the final extracted term within the specified output tags without additional commentary or internal formatting.
## Content
After isolating the correct term, immediately wrap it in the designated answer tags. Ensure the content inside the tags contains only the raw answer string, stripping all surrounding explanation, punctuation, or markdown to guarantee parser compatibility and adherence to task constraints.
