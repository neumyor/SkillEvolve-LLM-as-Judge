# Success Memory Item 1
## Title
Temporal-Action Entity Mapping
## Description
Use precise dates and specific event descriptions in the query to locate and extract the responsible entity from the context.
## Content
When a question specifies an exact date and a particular action (e.g., transfer, takeover, establishment), scan the retrieved documents for matching temporal markers paired with those action verbs. The subject noun directly associated with the date-action pair in the text is typically the correct answer.

# Success Memory Item 2
## Title
Multi-Source Consistency Confirmation
## Description
Cross-reference multiple retrieved documents to ensure the extracted entity aligns consistently across sources before finalizing.
## Content
Factual and historical queries often yield overlapping information across different sources. Compare how each document frames the same event to verify that the identified entity remains consistent. Relying on convergent evidence reduces attribution errors and strengthens confidence in the extraction.

# Success Memory Item 3
## Title
Constraint-Driven Output Structuring
## Description
Prioritize strict adherence to formatting requirements while keeping reasoning tightly coupled to contextual evidence.
## Content
Always reserve the final step for applying the exact output tags requested. During reasoning, filter out extraneous details and focus exclusively on mapping query constraints to context snippets. This minimizes cognitive load and prevents formatting deviations that could invalidate otherwise correct answers.
