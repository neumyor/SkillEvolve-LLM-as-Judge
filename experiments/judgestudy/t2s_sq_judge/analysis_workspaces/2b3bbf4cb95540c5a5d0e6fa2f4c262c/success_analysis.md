# Success Memory Item 1
## Title
Direct Lexical Mapping with Attribute Cross-Checking
## Description
For identification or definition queries, extract the exact target term by locating explicit equivalence statements in the context, then validate that all secondary descriptors in the prompt align with the retrieved information before finalizing the output.
## Content
1. Scan context for direct synonyms, translations, or explicit naming phrases linked to the prompt's key term.
2. Confirm contextual alignment by matching secondary details (e.g., geographic region, popularity status, historical timeframe) provided in the question.
3. Isolate the precise answer string without adding explanatory text or alternative interpretations.
4. Apply strict formatting rules immediately upon confirmation to ensure compliance.
