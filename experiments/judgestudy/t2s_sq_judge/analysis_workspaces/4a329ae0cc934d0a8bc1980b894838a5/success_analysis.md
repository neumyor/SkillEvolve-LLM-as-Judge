# Success Memory Item 1
## Title
Leverage Verbatim Context Matching
## Description
Use distinctive phrasing from the prompt to locate exact sentence matches in the retrieved documents.
## Content
Trivia and factual queries often reuse specific wording. Scan retrieved snippets for identical or near-identical phrases to quickly isolate the target information without requiring broad inference or external knowledge.

# Success Memory Item 2
## Title
Extract and Format Precisely
## Description
Output only the exact term found in the matching context, wrapped in the specified tags.
## Content
Avoid adding explanatory text or rephrasing when the context provides a direct, unambiguous answer. Strictly adhere to the requested output format to ensure compliance and maximize scoring metrics.

# Success Memory Item 3
## Title
Treat Document Convergence as Immediate Closure
## Description
Recognize when multiple retrieved documents contain identical phrasing to confirm accuracy without additional steps.
## Content
If several sources repeat the same fact using the prompt's exact language, treat this convergence as sufficient evidence. Proceed directly to finalizing the answer rather than initiating secondary searches or complex reasoning chains.
