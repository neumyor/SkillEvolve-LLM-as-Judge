# Success Memory Item 1
## Title
Prioritize Definitional Sources Over Contextual or Fandom References
## Description
When a query term maps to multiple entities in the context, distinguish between formal/trivia definitions and niche, modern, or promotional usage.
## Content
Scan retrieved snippets for explicit framing language such as "nickname," "known as," or catalog listings. Favor sources that treat the term as a geographic, historical, or official identifier rather than a sports mascot, social media handle, or event theme. Resolve ambiguity by weighting encyclopedic or reference-style contexts higher than community-driven or marketing mentions.

# Success Memory Item 2
## Title
Cross-Validate Leading Hypotheses Against Independent Snippets
## Description
Confirm the most likely answer by checking for alignment across multiple distinct documents before committing to a final response.
## Content
If initial matches point to one entity but others suggest alternatives, explicitly compare their contextual framing. Require at least two non-redundant sources to share the same definition or association. Discard isolated mentions that lack supporting definitional weight or contradict the majority of authoritative snippets. Consistency across independent documents signals the intended target.

# Success Memory Item 3
## Title
Isolate Final Output Within Mandated Tags
## Description
Strip all internal reasoning, justification, and conversational text from the final response, delivering only the exact answer string inside the required container.
## Content
After determining the correct entity, format the output strictly according to instructions. Omit explanations, alternative considerations, or meta-commentary. Ensure the payload consists solely of the target value wrapped in the specified tags to guarantee seamless parsing and accurate metric scoring.
