# Success Memory Item 1
## Title
Resolve Cross-Cultural Mythological Mappings
## Description
When a query specifies a particular cultural origin for a deity or figure, leverage explicit counterpart statements in the context to translate known names into the target tradition, then validate domain attributes across multiple sources.
## Content
Identify cultural constraints in the prompt (e.g., "Greek," "Roman," "Norse"). Search context for direct equivalence phrases like "counterpart is," "known as," or "version of." Map the queried concept to the target culture's name using these links. Confirm the selected entity matches all requested attributes (domain, gender, epithets) by checking consistency across at least two context snippets before formatting the final answer.
