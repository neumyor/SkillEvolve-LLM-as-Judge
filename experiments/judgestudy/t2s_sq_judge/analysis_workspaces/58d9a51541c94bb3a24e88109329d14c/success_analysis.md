# Success Memory Item 1
## Title
Cross-Document Semantic Bridging for Incomplete Prompts
## Description
Resolve trivia or cloze-style questions by linking partial context matches to explicit definitions found in separate retrieved documents.
## Content
1. Isolate distinctive identifiers from the prompt (e.g., specific dates, demographics, or feature lists).
2. Locate the exact prompt phrasing in the context to confirm the query's premise.
3. Scan additional documents for explicit definitions or labels that correspond to those same identifiers.
4. Combine the confirmed premise with the discovered label to generate the final answer.
