# Success Memory Item 1
## Title
Contextual Clue Extraction for Trivia Prompts
## Description
Systematically isolate missing elements in trivia or Jeopardy-style questions by leveraging explicit contextual markers and validating against known entity patterns.
## Content
Scan retrieved documents for direct clue-answer pairings, structural delimiters, or explicit labels tied to the prompt's phrasing. Identify the target entity type (e.g., song title, artist name) and use the provided context to match partial phrases with complete known instances. Rely primarily on contextual evidence to confirm the deduction, then apply the exact output formatting specified in the initial instructions without deviation.
