# Success Memory Item 1
## Title
Constraint-Driven Context Scanning
## Description
Decompose the prompt into discrete temporal, ordinal, and categorical parameters to direct focused document evaluation.
## Content
Extract specific markers (e.g., year, organizational affiliation, leadership sequence) from the question and use them as explicit filters when reviewing retrieved text. Prioritize passages that simultaneously satisfy all identified constraints rather than relying on broad thematic matches.

# Success Memory Item 2
## Title
Cross-Source Corroboration
## Description
Establish high confidence in factual claims by identifying consistent patterns across multiple independent documents.
## Content
When evaluating retrieved context, treat repeated explicit statements about the same entity or event as reliable signals. Synthesize findings only after confirming that at least two distinct sources independently report the same core fact, reducing reliance on isolated or potentially noisy snippets.

# Success Memory Item 3
## Title
Direct Constraint-to-Output Mapping
## Description
Translate confirmed contextual findings directly into the requested answer format without intermediate narrative.
## Content
Once the exact term or phrase satisfying the prompt's constraints is identified, isolate it and apply the required structural tags immediately. Omit explanatory text, step-by-step breakdowns, or hedging language in the final output to maintain precision and compliance with formatting rules.
