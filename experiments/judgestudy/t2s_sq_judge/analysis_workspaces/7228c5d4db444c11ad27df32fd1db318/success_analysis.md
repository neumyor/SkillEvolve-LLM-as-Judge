# Success Memory Item 1
## Title
Constraint-Driven Entity Resolution
## Description
Decompose descriptive prompts into explicit attributes and align them with contextual evidence to isolate the precise target entity.
## Content
1. Extract key identifiers from the query (e.g., creator, subject type, role, or defining event).
2. Scan retrieved passages for overlapping terminology and narrative details that satisfy each identifier.
3. Pinpoint the single named entity that meets all conditions simultaneously.
4. Deliver the extracted entity using the exact required syntax, avoiding supplementary explanation.
