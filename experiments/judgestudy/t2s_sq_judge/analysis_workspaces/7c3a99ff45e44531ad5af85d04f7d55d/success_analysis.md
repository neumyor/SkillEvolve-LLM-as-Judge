# Success Memory Item 1
## Title
Decompose and Cross-Reference Compound Clues
## Description
Systematically break down descriptive or trivia-style prompts into discrete factual components and match them against retrieved text attributes.
## Content
When encountering queries phrased as concise descriptions or riddles, isolate each distinct phrase (e.g., geographic origin, notable work, professional movement). Scan retrieved documents to identify which source simultaneously satisfies all isolated components. Prioritize contexts where location, subject matter, and field/category align directly with the prompt's wording. Once every component finds a direct textual match within a single entity or concept, synthesize the identified subject as the final answer.
