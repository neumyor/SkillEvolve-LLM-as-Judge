# Success Memory Item 1
## Title
Targeted Phrase Anchoring
## Description
Leverage distinctive quotes or unique descriptive phrases from the prompt as direct search anchors within retrieved documents to rapidly isolate the target entity.
## Content
When a question contains a highly specific string or unusual phrasing, scan the context for exact or near-exact matches of that phrase. This technique bypasses tangential information and immediately flags the relevant passage, significantly reducing search space and cognitive load.

# Success Memory Item 2
## Title
Multi-Clue Convergence Verification
## Description
Cross-validate all distinct prompt attributes (e.g., cultural symbolism, physical traits, historical labels) against a single candidate to ensure complete alignment before concluding.
## Content
Questions frequently combine thematic cues with factual descriptors. After an initial match is found via one clue, systematically check the same context snippet to confirm it also satisfies the remaining conditions. Advance only when all independent clues converge on one consistent subject, preventing premature or partial matches.

# Success Memory Item 3
## Title
Minimalist Entity Extraction
## Description
Isolate the core noun or proper name corresponding to the matched entity, stripping away explanatory context to produce a concise, tag-compliant final output.
## Content
Once contextual alignment confirms the target, extract only the precise term requested. Omit synonyms, supporting details, or conversational framing. This ensures strict compliance with automated parsing requirements and maximizes recognition accuracy in downstream evaluation metrics.
