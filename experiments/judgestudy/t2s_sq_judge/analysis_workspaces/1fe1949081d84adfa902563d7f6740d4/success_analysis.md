# Success Memory Item 1
## Title
Resolving Derivative References via Explicit Contextual Links
## Description
Extract the original subject when a query describes a character, work, or concept as a parody, imitation, or adaptation.
## Content
Identify core entities and relationship types in the prompt. Scan the context for direct statements containing relational markers (e.g., "parody of," "based on," "imitation of," "inspired by"). Isolate the entity named as the source or inspiration, as these declarative links directly answer questions about underlying references. Rely on exact keyword alignment and straightforward sentence extraction rather than multi-step inference.
