# Success Memory Item 1
## Title
Exact-Pattern Matching for Clue-Based Queries
## Description
For trivia or quiz-style questions, scan retrieved context for verbatim phrase matches or structured Q&A formats instead of performing multi-hop synthesis.
## Content
Isolate distinctive keywords or full phrases from the prompt and search the context for identical strings. When a document appears to be a dataset dump, leaderboard, or Q&A archive containing the exact query, directly extract the paired answer. This approach capitalizes on pre-indexed knowledge structures often present in search results, reducing hallucination risk and computation overhead.
