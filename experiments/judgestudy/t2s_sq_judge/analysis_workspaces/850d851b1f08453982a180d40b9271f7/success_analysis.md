# Success Memory Item 1
## Title
Prioritize Relational Addresses Over Formal Names
## Description
When a question asks how a character is addressed by others, shift focus from given names or nicknames to familial, professional, or social titles used within the narrative.
## Content
Identify the character's role in the story (e.g., elder, mentor, authority figure) and extract the corresponding relational term. Contextual character summaries often explicitly pair the known identifier with the common address; use this pairing as the primary signal for the expected response.

# Success Memory Item 2
## Resolve "Named X, Called Y" Ambiguity
## Description
For prompts contrasting a character's canonical name with their everyday address, determine which term aligns with in-universe usage patterns rather than etymology or official records.
## Content
Scan retrieved text for frequency and consistency of address terms among peers or family members. Favor the term that appears in dialogue references, episode guides, or character profiles as the default mode of address, treating formal names as secondary identifiers.

# Success Memory Item 3
## Aggregate Cross-Source Naming Conventions
## Description
Use multiple context snippets to confirm consistent naming behavior before finalizing an answer, reducing reliance on isolated or ambiguous mentions.
## Content
Cross-reference character lists, episode guides, and fan wikis to verify that the target identifier is consistently paired with the known name. When sources repeatedly use the same relational or colloquial term alongside the provided name, adopt that term as the definitive answer for audience-facing queries.
