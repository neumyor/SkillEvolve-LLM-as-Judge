# Success Memory Item 1
## Title
Direct Entity Mapping for Factual Queries
## Description
Scan retrieved context for exact or semantic alignment with the core subject and defining descriptors in the prompt to rapidly isolate the target information.
## Content
When processing direct factual or trivia questions, prioritize locating documents where titles or opening sentences explicitly contain the key terms from the query. Map the question's defining characteristics directly to candidate entities in the context to narrow down options efficiently without overcomplicating the search.

# Success Memory Item 2
## Title
Multi-Snippet Consistency Check
## Description
Confirm the identified answer by ensuring that multiple independent context excerpts consistently point to the same entity or fact.
## Content
Before finalizing a response, cross-reference at least two separate context snippets to ensure they independently support the same conclusion. This approach minimizes reliance on isolated or potentially misleading passages and builds confidence in the selected entity through converging evidence.

# Success Memory Item 3
## Title
Constraint-Driven Output Formatting
## Description
Strictly adhere to requested structural boundaries and extract only the minimal required phrase without additional commentary.
## Content
Match the exact formatting instructions provided in the prompt (such as specific delimiters or tags) and limit the extracted content to the precise entity or short phrase requested. Avoid adding explanatory text, alternative names, or contextual details unless explicitly required by the task.
