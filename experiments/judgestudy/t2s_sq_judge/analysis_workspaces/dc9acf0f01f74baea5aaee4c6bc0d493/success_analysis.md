# Success Memory Item 1
## Title
Identify Definition-Style Queries
## Description
Detect when the prompt functions as a lexical definition or crossword clue to prioritize appropriate knowledge sources.
## Content
Treat prompts matching common dictionary or puzzle formats as requests for precise term identification rather than explanatory answers. Focus retrieval on glossaries, thesauruses, and crossword databases to locate exact lexical matches.

# Success Memory Item 2
## Title
Prioritize Exact Phrasal Alignment in Definitions
## Description
When multiple candidate terms appear, evaluate them against the retrieved context to select the one whose definition most closely mirrors the prompt's specific wording.
## Content
Cross-reference candidate terms with dictionary or solver snippets. Discard synonyms that describe related concepts but lack the exact phrasing or nuance requested. Choose the term where the contextual definition directly restates the prompt.

# Success Memory Item 3
## Title
Utilize Puzzle Database Patterns for Lexical Confirmation
## Description
Use recurring patterns in crossword solver and puzzle database contexts to validate term-clue pairings when standard definitions are ambiguous.
## Content
When dictionary definitions offer multiple valid options, look for explicit clue-answer mappings in puzzle solver contexts. High-frequency or standardized clue phrases in these databases often indicate the expected canonical answer for trivia or definition-based tasks.
