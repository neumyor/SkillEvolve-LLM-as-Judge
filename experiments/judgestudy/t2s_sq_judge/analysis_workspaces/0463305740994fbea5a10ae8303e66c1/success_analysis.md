# Success Memory Item 1
## Title
Decompose Procedural Prompts into Search Anchors
## Description
Convert descriptive or formulaic questions into explicit operational keywords to guide targeted context scanning.
## Content
When a prompt describes a calculation method or geometric property without naming the target, isolate the core mathematical operations and variables (e.g., "add parallel sides," "divide by 2," "multiply by height"). Use these extracted phrases as direct textual anchors to scan the retrieved documents, bypassing irrelevant definitions and focusing on exact procedural matches.

# Success Memory Item 2
## Title
Cross-Reference Operations with Contextual Definitions
## Description
Validate the identified concept by ensuring every step in the prompt maps directly to a single entity in the retrieved documents.
## Content
Match each extracted operation from the prompt against the context snippets. Confirm that all described steps are cohesively attributed to one specific term or shape in the source material. Discard partial matches where only some operations align, prioritizing complete procedural correspondence before committing to an answer.

# Success Memory Item 3
## Title
Resolve Terminology Variants Using Source Frequency
## Description
Select the final label based on the most consistent or explicitly defined terminology found in the context.
## Content
If multiple valid names exist for the identified concept (e.g., regional differences, synonyms, or alternate academic terms), default to the term most frequently cited or formally introduced in the retrieved documents. This ensures the output aligns with the provided evidence base and maintains consistency with the context's framing.
