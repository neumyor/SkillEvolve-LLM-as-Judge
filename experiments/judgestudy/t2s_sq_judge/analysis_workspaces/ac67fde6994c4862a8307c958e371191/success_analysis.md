# Success Memory Item 1
## Title
Constraint-Based Entity Filtering
## Description
Isolate core descriptive attributes from the query and systematically match them against candidate entities in the context, discarding partial matches.
## Content
Extract defining parameters (e.g., geographic location, political status, physical characteristics) from the question. Scan retrieved documents for entities that satisfy every constraint simultaneously. Explicitly rule out distractors that share superficial keywords but fail critical criteria, ensuring only fully compliant candidates remain.

# Success Memory Item 2
## Title
Pattern-Aware Context Alignment
## Description
Detect standardized or templated query formats and use structural cues to guide information extraction and validation.
## Content
Recognize recurring patterns such as quiz clues, fixed phrases, or metadata tags in both the prompt and context. Leverage these structural signals to prioritize relevant documents, anticipate the required answer format, and cross-reference supporting details to confirm alignment before finalizing the response.
