# Success Memory Item 1
## Title
Direct Keyword-to-Definition Mapping
## Description
Efficiently locate answers by scanning retrieved documents for exact keyword overlaps between the query and explicit definitional statements.
## Content
When processing definition-based questions, prioritize extracting sentences that directly pair the queried concept with its description. Match core query terms against context phrases to identify unambiguous definitions without unnecessary cross-document synthesis.

# Success Memory Item 2
## Title
Structural Phrase Alignment for Term Identification
## Description
Use the syntactic structure of the question to filter contextual noise and isolate the precise target term.
## Content
Frame the search intent around the question's grammatical pattern. Scan context for matching structural templates like "[Term] is the [description]" to quickly distinguish the correct answer from related but incorrect concepts.

# Success Memory Item 3
## Title
Minimalist Answer Extraction
## Description
Isolate and output only the exact requested entity, adhering strictly to formatting constraints.
## Content
After identifying the correct term through context matching, strip away surrounding explanations or alternative candidates. Extract solely the precise noun or phrase requested and apply the required output tags immediately to ensure compliance and reduce token waste.
