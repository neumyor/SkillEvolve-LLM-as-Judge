# Success Memory Item 1
## Title
Direct Attribution Extraction for Creator/Developer Queries
## Description
Systematically locate explicit credit statements in the context to extract the named individual responsible for a specific creation or development.
## Content
When the question asks who created, developed, or bred a specific item, scan the context for direct attribution phrases (e.g., "developed by," "bred by," "created by"). Identify the named entity explicitly linked to the target subject in these passages. If multiple context snippets confirm the same attribution, prioritize that entity. Extract only the precise name, omit all explanatory text, and apply the required output formatting strictly. Do not infer or supplement with external knowledge.
