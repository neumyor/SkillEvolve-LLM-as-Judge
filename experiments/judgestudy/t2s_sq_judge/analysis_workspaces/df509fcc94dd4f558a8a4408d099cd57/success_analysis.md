# Success Memory Item 1
## Title
Keyword-Driven Context Scanning
## Description
Systematically match core query terms against retrieved document snippets to identify relevant passages.
## Content
Extract key nouns and phrases from the prompt and scan the provided context for exact or semantic matches. Prioritize documents where multiple query terms co-occur in close proximity, as this indicates high relevance and filters out tangential results.

# Success Memory Item 2
## Title
Cross-Document Consensus Alignment
## Description
Validate extracted answers by checking for consistent mentions across multiple retrieved sources.
## Content
After identifying a candidate answer from one document, scan remaining context snippets for corroborating evidence. When multiple independent sources highlight the same term or fact, confidently select it as the final answer to minimize noise or isolated outliers.

# Success Memory Item 3
## Title
Constraint-Compliant Answer Extraction
## Description
Formulate the final response by directly extracting the matched concept and applying strict formatting rules.
## Content
Avoid adding external knowledge or elaboration unless explicitly requested. Strip the identified answer to its core term or phrase, then wrap it precisely in the required tags. Maintain brevity to align with evaluation metrics that favor exact matches.
