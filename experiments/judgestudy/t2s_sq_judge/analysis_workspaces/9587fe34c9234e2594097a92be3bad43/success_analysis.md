# Success Memory Item 1
## Title
Direct Snippet Alignment for Factual Queries
## Description
Prioritize extracting answers from passages that mirror the question's specific phrasing or explicitly state the outcome under the given conditions.
## Content
When processing trivia or fact-based prompts, scan retrieved documents for near-exact matches to key terms (dates, conditions, entities). Extract the answer directly from sentences that explicitly resolve the query, bypassing unnecessary inference when the text provides a clear, standalone statement.

# Success Memory Item 2
## Title
Contextual Convergence for Certainty
## Description
Leverage multiple independent snippets that address the same core condition to establish confidence without external knowledge.
## Content
Cross-reference distinct retrieved sources that point to the same entity or outcome under the specified parameters. Treat consistent identification across separate documents as sufficient grounds for selection, filtering out tangential or contradictory information that does not align with the query's precise constraints.

# Success Memory Item 3
## Title
Constraint-First Output Formatting
## Description
Isolate the final answer generation step to strictly comply with structural requirements, suppressing all explanatory or conversational text.
## Content
Once the target information is identified, immediately apply the required output template. Remove all intermediate reasoning, hedging, or contextual elaboration from the final response to ensure strict compliance with formatting rules and optimize for automated evaluation metrics.
