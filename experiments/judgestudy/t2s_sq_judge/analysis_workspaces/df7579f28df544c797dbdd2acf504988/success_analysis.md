# Success Memory Item 1
## Title
Resolve Implicit Queries for Standalone Quotes
## Description
When a prompt consists solely of a famous quote or phrase without an explicit question, infer the underlying intent as identifying its origin or creator.
## Content
Treat isolated literary lines, sayings, or excerpts as requests for authorship or source attribution. Scan the context for recurring names or titles linked to the text. Prioritize the most consistently credited entity and frame the response around that origin point rather than attempting to complete the quote or analyze its meaning.

# Success Memory Item 2
## Title
Leverage Recurring Attribution Signals
## Description
Identify the correct origin by tracking how consistently the quote is linked to specific creators across different context snippets.
## Content
Compare document titles and extracted phrases to spot repeated author-work pairings. When multiple independent passages associate the same name with the excerpt, treat this convergence as the strongest signal. Use this recurring pattern to anchor the final selection before formatting.

# Success Memory Item 3
## Title
Extract and Isolate Core Entities
## Description
Condense the confirmed attribution into a minimal, precise string formatted strictly within the required answer tags.
## Content
Once the primary source is identified, strip away supplementary details like full titles, publication dates, or contextual explanations. Return only the essential identifier (typically the author's name or exact work title) directly inside the answer tags to maintain compliance and maximize clarity.
