# Success Memory Item 1
## Title
Constraint-Aligned Cross-Reference Extraction
## Description
Map explicit query parameters to retrieved text, then confirm the answer by identifying consistent signals across multiple independent context passages.
## Content
Decompose the question into specific filters (e.g., subject, timeframe, attributes). Scan all available context snippets to locate text satisfying every filter simultaneously. Select the candidate that appears consistently across multiple independent passages, as convergence indicates higher reliability. Extract only the exact matching term or phrase, strip surrounding narrative, and apply the mandated output tags directly.
