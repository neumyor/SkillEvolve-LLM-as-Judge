# Success Memory Item 1
## Title
Exact Phrasing Match Detection
## Description
Prioritize scanning retrieved snippets for verbatim or near-verbatim overlaps with the question's specific phrasing, especially for definitional or trivia-style prompts.
## Content
When a query uses distinctive descriptive clauses, search the context for identical keyword sequences. A direct textual overlap typically indicates a ready-made answer pair embedded in the source material.

# Success Memory Item 2
## Title
Pattern Recognition for Study Materials
## Description
Identify when retrieved documents follow educational formats (flashcards, glossaries, Q&A lists) that mirror the prompt's structure.
## Content
Treat these sources as direct lookup tables. If the question matches a known format, locate the corresponding answer term positioned immediately after or within the same sentence as the matching definition.

# Success Memory Item 3
## Title
Minimalist Extraction & Strict Formatting
## Description
Bypass complex reasoning or cross-document synthesis when a single snippet provides a clear, unambiguous answer.
## Content
Isolate the target term directly from the matched snippet. Apply the required output tags immediately, ensuring compliance with length and formatting constraints without adding extraneous explanation.
