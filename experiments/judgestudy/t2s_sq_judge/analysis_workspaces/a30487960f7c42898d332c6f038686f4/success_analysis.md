# Success Memory Item 1
## Title
Discrete Option Alignment
## Description
Prioritize context segments that explicitly state one of the provided choices or contain component values that sum to a choice.
## Content
When faced with constrained-value questions, scan retrieved documents for direct numerical matches to the offered options. If an exact figure is absent, identify additive breakdowns (e.g., separate anatomical features or categories) and calculate their sum to determine which option aligns with the combined total.

# Success Memory Item 2
## Title
Component-to-Total Corroboration
## Description
Confirm a candidate answer by checking that contextual sub-components logically combine to form the stated total.
## Content
Extract both the explicit count and its descriptive breakdown from the context. Ensure internal consistency by verifying that the sum of the parts matches the whole and corresponds to the selected option, preventing errors from misreading partial or isolated statistics.

# Success Memory Item 3
## Title
Constraint-Driven Output Isolation
## Description
Suppress all intermediate reasoning and deliver only the finalized value within the exact formatting boundaries specified by the prompt.
## Content
Once the correct answer is identified and internally corroborated, strip away explanatory text, units, or conversational markers. Output strictly the raw answer string enclosed in the required tags to maintain compliance and maximize downstream parsing success.
