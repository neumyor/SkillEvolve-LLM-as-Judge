# Success Memory Item 1
## Title
Direct Phrasing Alignment with Retrieved References
## Description
Prioritize exact or near-exact textual matches from retrieved documents when the prompt closely mirrors known reference material.
## Content
Scan context snippets for sequences of keywords or phrases that mirror the question structure. When a source (e.g., flashcards, trivia databases) contains the identical combination of clues, treat it as a direct mapping signal rather than requiring independent synthesis. This accelerates identification and reduces overcomplication.

# Success Memory Item 2
## Title
Multi-Constraint Candidate Filtering
## Description
Decompose compound questions into discrete criteria and systematically test each candidate against all conditions simultaneously.
## Content
Extract distinct clues (e.g., historical date, geographic distance, administrative rank) and evaluate potential entities against every constraint. Discard candidates that satisfy only a subset of the clues. Continue narrowing until a single entity aligns with the complete set of requirements, ensuring robust selection even when multiple locations share overlapping features.

# Success Memory Item 3
## Title
Status-Based Disambiguation
## Description
Leverage explicit administrative or hierarchical descriptors to differentiate between geographically or historically related locations.
## Content
When context mentions multiple places tied to the same event or region, use status markers (such as "provincial capital," "largest city," or "town") to resolve ambiguity. These structural cues often serve as definitive filters that separate the correct answer from plausible but incorrect alternatives mentioned in the same passage.
