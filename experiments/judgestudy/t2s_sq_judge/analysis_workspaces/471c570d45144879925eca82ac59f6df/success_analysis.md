# Success Memory Item 1
## Title
Structural Component Mapping
## Description
Identify the foundational elements required by the prompt's condition and locate their corresponding counterparts in the retrieved context.
## Content
When a question specifies one required component, scan the context for definitions of completeness that list paired or grouped elements. Map the missing counterpart directly from these structural definitions to fill the gap, treating the context's explicit breakdown as the primary reference framework.

# Success Memory Item 2
## Title
Cross-Snippet Definition Convergence
## Description
Verify the target concept by checking for consistent definitions across multiple retrieved documents.
## Content
If several independent context passages explicitly state the same set of requirements or components for a given concept, treat this consensus as high-confidence evidence. Prioritize terms that appear repeatedly across different sources to filter out niche variations or incomplete excerpts.

# Success Memory Item 3
## Title
Direct Terminology Alignment
## Description
Extract the exact term used in the context rather than paraphrasing or inferring synonyms.
## Content
Match the prompt's syntactic structure to the precise vocabulary found in the authoritative passages. Output the identified term directly within the required format, ensuring strict adherence to the wording established by the source material to maximize lexical overlap scoring.
