# Success Memory Item 1
## Title
Multi-Constraint Entity Decomposition
## Description
Break down the query into explicit categorical and quantitative requirements, then systematically scan retrieved documents to locate entities that satisfy every condition simultaneously.
## Content
Isolate core parameters such as industry type, geographic scope, and minimum thresholds. For each candidate organization found in the context, verify alignment against all extracted parameters before advancing. Prioritize entities where the documented metrics explicitly meet or exceed the stated limits.

# Success Memory Item 2
## Title
Contextual Distractor Filtering
## Description
Identify and eliminate partial matches that share surface-level keywords but fail on critical distinguishing attributes like location, sector, or operational scale.
## Content
When multiple organizations appear in the text, compare their documented profiles against the question's strict boundaries. Flag mismatches (e.g., correct industry but wrong state, or correct state but different business type) and discard them early. Maintain focus on the intersection of all required attributes rather than isolated keyword overlaps.

# Success Memory Item 3
## Title
Cross-Document Attribute Synthesis
## Description
Aggregate corroborating details from multiple retrieved sources to construct a complete entity profile and resolve ambiguous or fragmented information.
## Content
If several documents reference the same organization, combine their statements to form a unified factual baseline. Use consistent data points across sources to validate that the entity meets the query's numerical or categorical thresholds. Rely on the most specific, directly relevant figures to finalize the selection.
