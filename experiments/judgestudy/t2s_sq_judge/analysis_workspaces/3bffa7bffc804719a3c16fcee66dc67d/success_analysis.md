# Success Memory Item 1
## Title
Resolve Foreign or Niche Terms via Contextual Definition
## Description
When a query contains a non-standard, foreign, or culturally specific term, prioritize locating its explicit definition or translation within the retrieved documents rather than relying on external knowledge.
## Content
Scan context for direct translations, etymological notes, or descriptive phrases linked to the target term. Use the context's exact phrasing to ground the answer, ensuring alignment with the provided evidence.

# Success Memory Item 2
## Title
Map Descriptive Clues to Identified Concepts
## Description
Cross-reference contextual descriptors (e.g., "seen on coins," "national emblem") with the resolved term to confirm semantic relevance before finalizing the answer.
## Content
Verify that the concept matches all functional or visual cues in the prompt. If multiple candidates exist, select the one most directly supported by the intersection of the query's clues and the context's descriptions.

# Success Memory Item 3
## Title
Extract Core Noun for Direct Output
## Description
Distill the final response to the single most precise noun or phrase requested, stripping away explanatory text, historical context, or alternative names unless explicitly asked for.
## Content
Place the distilled answer strictly within the required tags. Avoid full sentences or qualifiers. Prioritize brevity and directness to maximize matching accuracy against expected outputs.
