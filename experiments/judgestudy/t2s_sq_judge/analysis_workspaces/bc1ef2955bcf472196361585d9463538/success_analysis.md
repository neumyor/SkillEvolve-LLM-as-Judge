# Success Memory Item 1
## Title
Direct Categorical Extraction
## Description
Locate explicit definitional statements in the context that classify the query's subject.
## Content
When processing trivia or completion-style questions, scan retrieved documents for sentences that directly define the target term. Extract the category or material noun immediately following classification phrases (e.g., "is a synthetic type of," "family of," "type of") to form the answer.

# Success Memory Item 2
## Title
Syntactic Clue Mapping
## Description
Align the structural pattern of the prompt with contextual phrasing to isolate the missing term.
## Content
Parse the question's grammatical structure to anticipate where the answer should appear in the context. Look for parallel constructions or direct object relationships that link the known entity to the unknown material, using the surrounding syntax to guide extraction.

# Success Memory Item 3
## Title
Authoritative Source Prioritization
## Description
Favor formal, encyclopedic context entries over informal mentions when determining precise terminology.
## Content
When multiple context snippets address the same topic, prioritize entries with structured definitions (such as Wikipedia or technical summaries). These sources typically use standardized terminology that directly matches trivia or academic prompts, reducing ambiguity from casual or fragmented references.
