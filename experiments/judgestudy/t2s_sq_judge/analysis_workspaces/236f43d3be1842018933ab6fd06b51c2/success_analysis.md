# Success Memory Item 1
## Title
Targeted Identifier Mapping
## Description
Decompose trivia prompts into specific named entities, dates, and titles to use as precise anchors for scanning retrieved text.
## Content
Extract unique attributes from the question (e.g., artist name, song titles, release years). Systematically scan context snippets for exact or near-exact co-occurrences of these attributes to directly isolate the target entity without relying on broad topic matching.

# Success Memory Item 2
## Title
Leverage Phrasing Parallels
## Description
Treat contextual sentences that structurally mirror the question as direct definitional links, extracting the missing variable from the immediate syntactic frame.
## Content
When search results contain phrasing nearly identical to the prompt, recognize this as a strong signal of a direct factual match. Extract the requested information directly from the surrounding clause, as the context is likely providing the exact association the query seeks.

# Success Memory Item 3
## Title
Cross-Document Attribute Reinforcement
## Description
Strengthen answer selection by verifying that multiple independent context passages consistently associate the query's attributes with the same target.
## Content
After identifying a potential answer, quickly check adjacent or separate documents to see if they repeat the same attribute-to-entity linkage. Prioritize answers that appear consistently across multiple sources to filter out tangential mentions or unrelated data.
