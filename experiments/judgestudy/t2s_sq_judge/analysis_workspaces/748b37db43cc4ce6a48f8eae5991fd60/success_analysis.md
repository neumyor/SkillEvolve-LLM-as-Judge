# Success Memory Item 1
## Title
Cross-Reference Prompt Descriptors with Retrieved Snippets
## Description
Align specific identifying details from the question (e.g., profession, action, object type) with corresponding phrases in the retrieved documents to isolate the relevant passage.
## Content
Scan context paragraphs for direct matches to unique question attributes to quickly locate the sentence containing the target answer, prioritizing snippets that contain multiple overlapping keywords from the prompt.

# Success Memory Item 2
## Title
Isolate Target Answer from Matching Context
## Description
Extract the precise noun or phrase that directly satisfies the question's core inquiry once the supporting context is confirmed.
## Content
Avoid paraphrasing or adding contextual fluff; retrieve only the exact entity name that completes the factual query based on the aligned text, ensuring the extracted term stands alone as the direct response.

# Success Memory Item 3
## Title
Enforce Required Response Structure
## Description
Apply the exact formatting constraints specified in the prompt immediately after extraction, ensuring strict compliance before submission.
## Content
Wrap the extracted answer in the designated tags, strip all intermediate reasoning or explanatory text from the final output, and confirm that the response contains only the requested structural format.
