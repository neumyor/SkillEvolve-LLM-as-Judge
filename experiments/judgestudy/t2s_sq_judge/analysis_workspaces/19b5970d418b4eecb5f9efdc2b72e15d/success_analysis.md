# Success Memory Item 1
## Title
Cross-Reference Temporal Markers with Contextual Entries
## Description
Align specific years or dates in the prompt with corresponding entities or titles found in the retrieved documents to establish direct reference points.
## Content
Use the query's temporal cues to scan and anchor relevant context passages. This transforms abstract clues into concrete data links, enabling precise identification of the target subject before extraction.

# Success Memory Item 2
## Title
Isolate the Invariant Core Entity
## Description
Extract the shared subject or base name that persists across multiple referenced titles, roles, or variations.
## Content
When a prompt contrasts different iterations of a concept (e.g., differing years or adjectives), focus on the constant element that unifies them. Discard peripheral details like actor names, sequel distinctions, or production notes to isolate the fundamental answer.

# Success Memory Item 3
## Title
Enforce Minimalist Final Output
## Description
Deliver only the precise target entity in the requested format, omitting reasoning, alternatives, or contextual padding.
## Content
For trivia or riddle-style queries resolved via context mapping, strip all intermediate steps from the final response. Return a single, unambiguous noun phrase that directly satisfies the prompt's constraints and matches standard evaluation metrics.
