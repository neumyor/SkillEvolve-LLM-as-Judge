# Success Memory Item 1
## Title
Semantic Alignment for Descriptive Queries
## Description
Map narrative clues and role-based descriptions directly to named entities in the context, prioritizing functional matches over exact phrasing.
## Content
When the prompt presents a riddle-like or descriptive statement, scan retrieved snippets for sentences that explicitly define characters, professions, or relationships. Extract the entity paired with those descriptors, even if the exact prompt phrasing appears in a different document or lacks an immediate answer in its snippet.

# Success Memory Item 2
## Title
Contextual Scope Filtering
## Description
Isolate the correct entity by evaluating semantic boundaries and discarding references that belong to unrelated works, authors, or plotlines.
## Content
If multiple potential names appear across the context, cross-check each against the prompt's specific constraints. Eliminate candidates tied to different stories, creative credits, or tangential mentions. Retain only the entity whose described attributes fully satisfy the prompt's conditions.

# Success Memory Item 3
## Title
Anchor-Based Entity Resolution
## Description
Resolve ambiguous or incomplete clues by linking parallel contextual statements that share core thematic or factual anchors.
## Content
When a direct answer is absent from the snippet containing the clue, identify adjacent or related passages that describe the same subject. Synthesize these contextual anchors to pinpoint the target entity, ensuring the final selection remains grounded in the provided text's explicit details.
