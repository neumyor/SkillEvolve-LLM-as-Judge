# Success Memory Item 1
## Title
Multi-Constraint Entity Resolution
## Description
Decompose factual queries into distinct verifiable attributes and cross-reference them against retrieved documents to isolate the correct target.
## Content
Extract explicit identifiers from the prompt (e.g., author, publication year, setting, key factions or events). Match each identifier against the retrieved context to find a single document that satisfies all conditions simultaneously. Use this convergence of constraints to confidently select the target entity and formulate a concise response without overcomplicating the reasoning chain.
