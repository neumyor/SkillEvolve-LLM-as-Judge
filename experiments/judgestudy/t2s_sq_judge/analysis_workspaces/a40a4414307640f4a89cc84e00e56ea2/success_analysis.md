# Success Memory Item 1
## Title
Exact Phrase Matching & Constraint Filtering
## Description
Leverage distinctive prompt phrasing to locate verbatim context matches, then apply explicit modifiers to eliminate ambiguous alternatives.
## Content
When processing questions with unique or quiz-like wording, scan retrieved documents for direct string overlaps. Use explicit contextual cues (e.g., location, timeframe, subject) to cross-verify the match and discard similar but incorrect candidates. Extract only the precise term required, maintaining strict compliance with output formatting constraints.
