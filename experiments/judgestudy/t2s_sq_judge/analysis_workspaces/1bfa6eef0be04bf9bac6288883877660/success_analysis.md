# Success Memory Item 1
## Title
Map Specific Varieties to Parent Categories
## Description
When a query lists distinct subtypes or varieties sharing a notable trait, identify the overarching group explicitly named alongside them in the retrieved text.
## Content
Scan the context for the recurring noun that consistently modifies or classifies the listed subtypes. Extract this parent category directly as the answer, relying on explicit textual grouping rather than external knowledge.

# Success Memory Item 2
## Title
Validate Through Cross-Document Keyword Convergence
## Description
Confirm the target answer by checking if multiple independent context passages consistently pair the prompt’s specific terms with a single broader concept.
## Content
Prioritize answers where the relationship between the specific examples and the proposed category is reinforced across several documents. This redundancy signals high confidence in the correct classification without needing complex inference.

# Success Memory Item 3
## Title
Extract Precise Category Nouns for Classification Queries
## Description
For taxonomy or group-identification questions, isolate the exact categorical term and avoid appending explanations, qualifiers, or full sentences.
## Content
Strip modifiers and contextual framing from the matched term. Deliver only the core category name inside the required tags to align with strict evaluation metrics and maintain conciseness.
