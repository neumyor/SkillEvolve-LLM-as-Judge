# Success Memory Item 1
## Title
Leverage Exact-Phrase Matching for Trivia Retrieval
## Description
When processing factoid or quiz-style questions, prioritize context snippets that contain the verbatim query to rapidly locate embedded Q&A structures.
## Content
Search the retrieved documents for the full question string. High-signal sources like flashcards, study guides, or quiz archives often embed the complete question-answer pair. Extract the corresponding answer directly from these matches instead of deriving it from tangential explanatory text.

# Success Memory Item 2
## Title
Resolve Conflicting Candidates via Contextual Framing
## Description
When multiple snippets suggest different answers, use surrounding narrative cues to identify the intended response and filter out distractors or common misconceptions.
## Content
Evaluate how each snippet frames the information. Articles discussing errors, blunders, or corrections typically highlight the accurate term alongside the incorrect one. Favor structured educational materials and explicit corrections over casual discussions or partial matches to isolate the expected answer.

# Success Memory Item 3
## Title
Maintain Strict Formatting with Minimal Derivation
## Description
Keep internal reasoning focused exclusively on answer confirmation and synonym alignment, then output immediately within the required delimiters to satisfy evaluation constraints.
## Content
Once the target term is identified, avoid extended physical derivations or alternative hypothesis testing. Confirm semantic equivalence if the context uses variations (e.g., "atmosphere" vs "air resistance"), then wrap the final selection in the specified tags without additional commentary or structural padding.
