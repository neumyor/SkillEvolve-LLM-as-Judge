# Success Memory Item 1
## Title
Resolve Truncated Trivia Quotes via Contextual Cross-Referencing
## Description
When the prompt or retrieved context contains an incomplete quote from a quiz or trivia question, identify the underlying event or theme and use semantically related snippets to infer the missing answer.
## Content
Match partial phrases to known trivia formats or historical events mentioned in other retrieved documents. Use explicit keywords or descriptive clues to bridge the gap between the truncated query and the complete answer.

# Success Memory Item 2
## Title
Exploit Keyword Co-occurrence in Fragmented Search Results
## Description
In fragmented search contexts where the exact answer isn't immediately visible, look for repeated keywords or thematic clusters that directly relate to the question's subject matter.
## Content
Scan retrieved snippets for terms that co-occur with the question's phrasing. Synthesize information across multiple short excerpts to reconstruct the full fact when a single document lacks the complete statement.

# Success Memory Item 3
## Title
Map Direct Quiz Clues to Event Descriptions
## Description
Recognize when a question follows a standard trivia format and treat the exact phrasing as a search anchor to locate descriptive documents that contain the missing term.
## Content
If initial retrieval returns only the clue, pivot to documents detailing the referenced event or topic. Extract the answer by aligning the question's grammatical structure with contextual details like activity names, object types, or historical accounts.
