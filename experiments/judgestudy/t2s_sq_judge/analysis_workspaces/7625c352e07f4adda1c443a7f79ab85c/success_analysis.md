# Success Memory Item 1
## Title
Leverage Verbatim Clue Matching for Trivia-Style Queries
## Description
Detect when a prompt is phrased as an incomplete statement or quiz clue, then prioritize locating the exact string within the retrieved context to rapidly anchor the subject domain.
## Content
Trivia and riddle-style questions often appear verbatim in educational or database sources. Scanning for exact phrase matches first provides immediate structural validation, allowing the model to bypass ambiguous interpretation and focus on extracting the target entity from the surrounding context.

# Success Memory Item 2
## Title
Cross-Reference Specialized Terms Against Glossary Entries
## Description
Isolate distinctive keywords, foreign vocabulary, or technical ranges in the prompt and map them to explicit definitions or usage examples found across multiple context documents.
## Content
When a query hinges on niche terminology, treat those terms as anchors. Locate documents that function as glossaries, guides, or expert breakdowns to connect the abstract clue to a concrete category. Synthesizing the definition from one source with the clue match from another creates a robust, self-consistent identification path.
