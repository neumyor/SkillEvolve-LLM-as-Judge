# Success Memory Item 1
## Title
Keyword-Guided Explicit Statement Extraction
## Description
Isolate the query's core subject and target attribute, then scan retrieved context for direct, unambiguous statements linking them, prioritizing exact keyword matches and cross-source consensus.
## Content
1. Decompose the question to identify key entities and the specific detail requested.
2. Filter retrieved passages using these keywords to locate direct assertions or definitions.
3. Cross-reference multiple snippets to confirm alignment and eliminate contextual noise.
4. Extract the precise term or phrase that directly answers the query.
5. Apply the required output format strictly, retaining only the essential answer.
