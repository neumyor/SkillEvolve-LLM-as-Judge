# Success Memory Item 1
## Title
Direct Relational Extraction from Explicit Context
## Description
Locate and extract the target entity by identifying explicit relationship statements in the retrieved context that directly connect the known entities to the unknown variable.
## Content
When the question asks for a specific attribute or relation involving named entities, scan the context for sentences that explicitly state those connections. If a passage directly links the given entities (e.g., familial, professional, or biographical ties), isolate the missing term that completes the relationship. Rely on exact phrasing matches and skip complex inference or multi-hop reasoning when the answer is explicitly provided in the text.
