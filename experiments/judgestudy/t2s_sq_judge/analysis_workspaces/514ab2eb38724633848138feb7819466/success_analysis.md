# Success Memory Item 1
## Title
Decode Acronyms Through Contextual Pattern Matching
## Description
Infer full expansions of abbreviated terms by aligning partial context references with standard institutional or geographical naming conventions.
## Content
Extract recognizable root components from the retrieved text, apply common structural templates (e.g., [Institution] in [Location]), and isolate the specific letter or segment requested by the prompt.

# Success Memory Item 2
## Title
Bridge Information Gaps with Established Naming Conventions
## Description
When direct answers are absent in the context, leverage widely accepted organizational naming patterns to logically complete the query.
## Content
Identify the primary entity mentioned in the snippets, recognize how similar organizations typically append location or descriptor suffixes, and use this structural logic to pinpoint the missing component.

# Success Memory Item 3
## Title
Enforce Positional Constraints During Extraction
## Description
Strictly adhere to positional or sequential requirements in the question when isolating the final answer from a broader concept.
## Content
Map the full expanded form back to the original abbreviation, count characters sequentially to locate the exact target, and extract only that specific element for the final output.
