# Success Memory Item 1
## Title
Slot-to-Keyword Context Mapping
## Description
Translate the missing information type in the question into a precise search term to locate the exact answer within the retrieved documents.
## Content
Identify the specific attribute requested (e.g., position, date, location) and scan the context for that exact word or its direct label. Extract the value appearing immediately alongside the subject entity, prioritizing explicit statements over implicit deductions.

# Success Memory Item 2
## Title
Context-Exclusive Answer Formation
## Description
Derive the final response solely from explicit statements in the provided context, bypassing external knowledge or complex reasoning chains.
## Content
When the retrieved snippets contain a direct factual match to the query, adopt that statement verbatim. Ignore tangential or conflicting information in other documents unless the primary context is ambiguous. Rely exclusively on the most direct textual evidence available within the prompt's scope.

# Success Memory Item 3
## Title
Constraint-Driven Output Wrapping
## Description
Apply the exact structural formatting rules to the determined answer before final submission.
## Content
Once the core answer is isolated, immediately enclose it within the mandated tags. Strip all conversational text, reasoning steps, or supplementary details from the final output block to ensure strict compliance with automated parsing requirements.
