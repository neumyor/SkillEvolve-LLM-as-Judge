# Success Memory Item 1
## Title
Direct Definition-to-Term Extraction
## Description
Map definitional queries to explicit glossary or dictionary entries in retrieved context to isolate the target term.
## Content
When processing a question structured as a definition, clue, or descriptive phrase, scan the retrieved documents for formal definitions, glossaries, or reference entries that mirror the query's wording. Identify the headword or subject explicitly defined in those passages. Output only the extracted term in the required format, bypassing complex reasoning when the context provides a direct lexical match.
