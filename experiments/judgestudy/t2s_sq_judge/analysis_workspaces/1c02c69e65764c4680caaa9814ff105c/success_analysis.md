# Success Memory Item 1
## Title
Cross-Reference Structural and Functional Descriptors
## Description
Resolve ambiguous or image-referencing prompts by identifying entities in the context that simultaneously satisfy both physical/molecular descriptions and stated practical uses.
## Content
When a question alludes to a visual structure or uses open-ended phrasing, scan the retrieved documents for explicit mentions of molecular geometry, bonding, or composition paired directly with the target function. Prioritize the specific compound that the context explicitly links to both attributes, rather than relying on external knowledge or partial keyword matches.

# Success Memory Item 2
## Title
Differentiate Specific Compounds from Broad Categories
## Description
Avoid defaulting to generic class names when the context provides a precise chemical identifier that better aligns with the query's constraints.
## Content
If the prompt asks for a "substance" or "molecule" with a specific role, evaluate whether the context distinguishes between general categories (e.g., "bleach," "oxidizers") and exact chemical names. Select the precise compound that matches the structural and usage clues present in the text, ensuring the answer reflects the granularity expected by the question.

# Success Memory Item 3
## Title
Anchor Selection to Explicit Contextual Pairings
## Description
Ground the final answer in direct, unambiguous statements within the retrieved documents rather than inferring from fragmented or tangential information.
## Content
Look for sentences that explicitly connect the candidate entity to both the structural hint and the functional requirement (e.g., stating both its molecular shape and its application as a bleaching agent). Use these direct textual anchors as the primary basis for the response, ensuring strict alignment with the provided context.
