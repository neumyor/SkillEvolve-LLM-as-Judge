# Success Memory Item 1
## Title
Isolate Core Factual Request from Stylized Prompts
## Description
Trivia prompts often use puns, metaphors, or indirect phrasing. Extract the fundamental factual inquiry while treating decorative language as non-essential framing.
## Content
When parsing the prompt, identify the specific entities named (e.g., book titles) and determine the exact attribute being requested. Map these directly to the retrieved context without overcomplicating the interpretation of stylistic flourishes or wordplay.

# Success Memory Item 2
## Title
Cross-Reference Entities Across Multiple Snippets
## Description
Strengthen answer confidence by verifying that the target entity appears consistently alongside the query keywords across different retrieved documents.
## Content
Scan all available context passages for repeated associations between the mentioned works and a single creator. Prioritize the entity that demonstrates clear, recurring linkage throughout the corpus rather than relying on a single isolated mention.

# Success Memory Item 3
## Title
Rely on Explicit Contextual Statements
## Description
Ground the final answer strictly in direct textual evidence from the context, avoiding deductive leaps or external knowledge assumptions.
## Content
If the context explicitly pairs the query terms with a specific name or fact, adopt that pairing as the answer. Maintain strict adherence to the provided material, outputting only the directly stated information in the required format without adding supplementary details.
