# Success Memory Item 1
## Title
Constraint-Based Entity Alignment
## Description
Map explicit prompt constraints to fragmented context snippets to resolve unnamed referents in trivia-style questions.
## Content
Extract core identifiers from the question (e.g., profession, institution, naming dedication, pronouns) and scan retrieved documents for matching keywords in titles, tags, and partial sentences. Cross-reference institutional affiliations and honorifics mentioned in snippets to confirm the exact entity, prioritizing matches that satisfy all grammatical and factual constraints before generating the final response.
