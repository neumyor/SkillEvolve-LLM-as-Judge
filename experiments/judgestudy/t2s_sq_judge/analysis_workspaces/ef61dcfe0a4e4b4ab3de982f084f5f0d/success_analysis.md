# Success Memory Item 1
## Title
Direct Entity Extraction via Keyword Anchoring
## Description
Locate the answer by anchoring search terms to the most specific nouns and dates in the prompt, then scan the context for explicit statements linking those anchors to the target entity.
## Content
Break down the question into core identifiers (e.g., creator, artwork, year). Use these as filters to quickly isolate relevant passages. Extract the named subject only when the text directly states the relationship or depicts the entity without requiring external knowledge.

# Success Memory Item 2
## Title
Contextual Constraint Alignment
## Description
Ensure the extracted entity satisfies all temporal, thematic, or descriptive parameters mentioned in the question before finalizing the response.
## Content
Cross-reference contextual details (such as dates, biographical events, or medium specifications) against the prompt's requirements. Confirm the candidate answer appears in passages that simultaneously satisfy every stated constraint.

# Success Memory Item 3
## Title
Immediate Structured Output Generation
## Description
Transition directly from logical confirmation to the required output format, omitting intermediate explanations in the final response to ensure strict compliance.
## Content
Once the correct entity is identified and aligned with the context, wrap it strictly within the designated tags. Maintain a clean separation between internal reasoning and the final deliverable to guarantee machine-readable success.
