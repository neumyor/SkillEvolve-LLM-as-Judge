# Success Memory Item 1
## Title
Resolve Contextual Placeholders via Document Metadata
## Description
When a retrieved passage contains a pronoun or placeholder (e.g., "this season," "it," "the city"), immediately check the corresponding document's title or heading, as it frequently serves as the direct answer.
## Content
Scan the context for exact phrase matches with the question. Once the relevant passage is located, extract the resolving term from the document's title or header rather than inferring it from surrounding text. This leverages structured metadata to bypass ambiguity, reduces reasoning overhead, and yields high-precision extractions for reference-resolution questions.
