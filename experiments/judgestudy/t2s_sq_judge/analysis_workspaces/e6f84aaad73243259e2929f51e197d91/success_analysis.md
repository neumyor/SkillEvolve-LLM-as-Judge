# Success Memory Item 1
## Title
Direct Clue-to-Text Mapping
## Description
Treat descriptive or trivia-style prompts as direct pointers to specific factual details in the retrieved context, bypassing unnecessary inference.
## Content
Map explicit keywords from the prompt (e.g., titles, roles, scene descriptions) directly to matching phrases in the context snippets. Prioritize exact lexical overlaps to quickly isolate the target entity without extrapolating beyond the provided text.

# Success Memory Item 2
## Title
Pragmatic Phrasing Interpretation
## Description
Resolve ambiguous or non-standard prompt phrasing by focusing on functional meaning rather than literal grammar.
## Content
When prompts use unconventional wording (e.g., "answers to"), interpret them functionally based on surrounding contextual cues. Use the retrieved text to ground the interpretation and avoid getting stalled on linguistic quirks or stylistic variations.

# Success Memory Item 3
## Title
Concise Alignment & Strict Formatting
## Description
Align the candidate against the strongest context match before outputting, adhering strictly to structural constraints.
## Content
After isolating a candidate, confirm its relevance by checking it against the most direct context snippet. Output only the precise entity name inside the required tags, omitting explanations, alternatives, or conversational filler to ensure compliance and precision.
