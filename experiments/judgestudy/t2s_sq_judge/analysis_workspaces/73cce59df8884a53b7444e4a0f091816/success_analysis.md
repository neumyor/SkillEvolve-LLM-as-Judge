# Success Memory Item 1
## Title
Direct Contextual Synonym Mapping
## Description
Locate explicit equivalence or naming relationships in retrieved text to resolve query terms.
## Content
When a prompt asks for the identity of a specific term or object, scan the context for direct definitional statements (e.g., "X is known as Y" or "locally referred to as Z"). Extract the primary term that aligns with the descriptive clues provided in the question.

# Success Memory Item 2
## Title
Core Query Isolation
## Description
Filter out conversational, rhetorical, or playful asides to identify the factual target.
## Content
Prompts frequently embed humor, myths, or rhetorical questions alongside the actual information request. Ignore these peripheral elements and focus strictly on the structural core of the question to determine the exact entity or fact being queried.

# Success Memory Item 3
## Title
Precise Term Extraction & Strict Formatting
## Description
Return only the exact matched term wrapped in the required output tags, omitting explanatory text.
## Content
After isolating the correct answer from the context, output it concisely using only the identified term. Wrap the result in the specified tags and avoid adding definitions, context summaries, or conversational filler to maximize precision and format compliance.
