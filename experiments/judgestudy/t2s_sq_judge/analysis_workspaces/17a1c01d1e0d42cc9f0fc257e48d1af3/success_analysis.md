# Success Memory Item 1
## Title
Targeted Keyword Mapping for Factual Queries
## Description
Align explicit question parameters with retrieved document snippets to isolate the correct answer.
## Content
Scan context for overlapping proper nouns, dates, and action verbs. Prioritize snippets that directly mirror the question's phrasing to extract the precise entity or value requested.

# Success Memory Item 2
## Title
Cross-Document Fact Validation
## Description
Validate extracted answers by cross-referencing multiple independent context passages.
## Content
Before finalizing, check that at least two separate documents support the same conclusion. This ensures the answer reflects a consistent pattern within the provided evidence rather than an isolated or ambiguous snippet.

# Success Memory Item 3
## Title
Constraint-Aligned Answer Structuring
## Description
Apply required output formatting immediately upon answer identification to ensure compliance.
## Content
Once the target information is isolated, wrap it in the specified delimiters without additional commentary. Maintain strict adherence to structural instructions throughout the generation process to meet evaluation criteria.
