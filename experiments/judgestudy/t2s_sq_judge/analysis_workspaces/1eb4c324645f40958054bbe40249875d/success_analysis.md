# Success Memory Item 1
## Title
Decompose Descriptive Constraints
## Description
Translate narrative or trivia prompts into discrete factual anchors to guide targeted matching within retrieved text.
## Content
Parse the query into specific identifiers (e.g., familial relationships, unique traits, outcomes) and use each as a direct search anchor within the provided context to isolate the target entity.

# Success Memory Item 2
## Title
Leverage Source Convergence
## Description
Treat consistent agreement across multiple retrieved passages as sufficient confirmation of entity identity and attributes.
## Content
When independent context snippets repeatedly describe the same subject matching the extracted constraints, use this pattern recognition to solidify the answer without requiring additional cross-referencing.

# Success Memory Item 3
## Title
Enforce Structural Compliance
## Description
Map the deduced answer directly to required output delimiters to ensure task completion and machine readability.
## Content
Upon confirming the target entity through constraint mapping and source alignment, immediately format the concise result inside the specified tags, omitting intermediate reasoning in the final output.
