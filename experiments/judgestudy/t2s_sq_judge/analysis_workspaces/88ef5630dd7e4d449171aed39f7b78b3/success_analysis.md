# Success Memory Item 1
## Title
Cross-Reference Multi-Sense Definitions
## Description
Align each component of a definitional clue with corresponding dictionary entries in the retrieved context to identify the unifying headword.
## Content
When a query presents multiple distinct meanings (e.g., literal and figurative), scan retrieved dictionary snippets for exact phrase matches. The word appearing as the primary entry across sources that covers all listed senses is the correct target.

# Success Memory Item 2
## Title
Normalize to Base Lexical Form
## Description
Convert identified inflected or variant forms from the context into their standard dictionary lemma for the final output.
## Content
Retrieved definitions often use conjugated, pluralized, or derived forms. Extract the root word that serves as the primary entry point in standard references to ensure consistency and accuracy.

# Success Memory Item 3
## Title
Prioritize Headword Alignment Over Synthesis
## Description
Rely on explicit headword-definition pairings in retrieved lexicographical data rather than generating novel terms.
## Content
For vocabulary or trivia questions, treat retrieved dictionary blocks as lookup tables. Match the prompt's semantic components directly to the definitions provided, then extract the associated title/headword without paraphrasing or creative interpretation.
