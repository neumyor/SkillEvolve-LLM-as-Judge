# Success Memory Item 1
## Title
Constraint-Driven Entity Mapping
## Description
Translate prompt requirements into explicit filters within the context.
## Content
Break down the query into distinct attributes (e.g., specific roles, media formats, biographical details). Systematically scan the retrieved context for sentences or phrases that simultaneously satisfy these attributes, isolating the common subject that bridges all conditions.

# Success Memory Item 2
## Title
Cross-Source Consistency Check
## Description
Confirm entity identity through consistent cross-referencing across independent context blocks.
## Content
When multiple documents independently link the same set of queried attributes to a single name, treat this overlap as definitive proof of correctness. Rely on this distributed consensus rather than isolated mentions to prevent misattribution or false positives.

# Success Memory Item 3
## Title
Minimalist Tagged Output Generation
## Description
Extract only the core identifying term and enforce strict formatting boundaries.
## Content
Once the target entity is confirmed, strip away all explanatory text, citations, or contextual framing. Output solely the precise name or phrase inside the designated XML tags to comply with structural requirements and maximize parsing reliability.
