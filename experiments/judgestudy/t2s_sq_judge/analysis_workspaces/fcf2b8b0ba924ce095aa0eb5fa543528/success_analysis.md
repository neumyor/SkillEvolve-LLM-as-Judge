# Success Memory Item 1
## Title
Alias-to-Primary-Entity Mapping
## Description
When a prompt uses a historical name, nickname, or alternative title, locate that specific term in the context and map it to the standard or contemporary entity it represents.
## Content
Scan retrieved documents for the exact alias or descriptive phrase provided in the query. Once found, identify the modern or widely recognized name associated with it. Prioritize extracting the primary entity over the historical variant, as the question typically seeks the current common designation.

# Success Memory Item 2
## Title
Cross-Source Concept Linking
## Description
Use multiple context snippets mentioning the key term to establish a consistent relationship between the clue and the target concept before finalizing the response.
## Content
Match distinctive phrases from the prompt against document titles and paragraphs. Synthesize overlapping mentions across different sources to confirm how the historical term relates to the main subject. Rely on consensus within the retrieved material to solidify the connection, avoiding reliance on a single potentially ambiguous passage.

# Success Memory Item 3
## Targeted Noun Extraction
## Description
For definition-style or clue-based prompts, strip narrative details from the context to isolate the single core noun or noun phrase that satisfies the description.
## Content
Ignore supplementary information such as inventors, dates, locations, or brand histories unless explicitly requested. Focus exclusively on identifying the central object or food item that matches the descriptive clue. Output only that isolated entity in the required format to maintain precision and compliance.
