# Success Memory Item 1
## Title
Prioritize Cultural Reference Mapping
## Description
Treat trivia-style prompts as direct pointers to established pop culture or common knowledge rather than requiring complex deduction.
## Content
When a question uses quiz-bowl phrasing or references iconic character tropes, immediately link the key entities to their most famous associated work. Formulate a direct answer based on this recognition before investing time in extensive retrieval or analysis.

# Success Memory Item 2
## Title
Filter Context for Direct Confirmation
## Description
Use retrieved documents strictly to confirm the initial hypothesis, disregarding semantically similar but factually irrelevant results.
## Content
Scan snippets for exact phrase matches or explicit confirmations of the core association. Ignore tangential documents that share keywords but address different topics. Accept the answer once the context supports the primary link, avoiding overcomplication from noise.

# Success Memory Item 3
## Title
Enforce Strict Output Isolation
## Description
Strip all reasoning, meta-commentary, and verification notes from the final response to guarantee clean machine parsing.
## Content
After confirming the answer, discard the thought process entirely. Output only the required delimiter tags containing the exact answer string. Maintain zero conversational filler to prevent evaluation penalties and ensure compliance with automated grading systems.
