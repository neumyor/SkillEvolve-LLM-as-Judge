# Success Memory Item 1
## Title
Isolate Entity and Query Attribute
## Description
Deconstruct the prompt to explicitly identify the target subject and the specific factual dimension being requested before processing the context.
## Content
Transform shorthand or implicit prompts into structured targets (e.g., Subject: Muhammad Ali → Attribute: pre-name change identifier). This focuses attention on relevant passages and filters out tangential biographical details that do not address the core query.

# Success Memory Item 2
## Title
Prioritize Mainstream Variants Over Edge Cases
## Description
When retrieved text contains multiple valid forms, aliases, or temporal states for a single fact, default to the most frequently cited or widely recognized version.
## Content
Contexts often list full legal names, temporary aliases, and common usage interchangeably. Select the concise, standard variant that aligns with general reference expectations unless the prompt explicitly demands a specific iteration or timeframe.

# Success Memory Item 3
## Enforce Structural and Length Constraints
## Description
Deliver the finalized answer strictly within the mandated formatting tags, omitting all reasoning, qualifiers, or supplementary text.
## Content
Factoid responses require maximum signal-to-noise ratio. Once the optimal value is determined, strip away contextual explanations and output only the distilled phrase inside the required delimiters to match expected evaluation structures.
