# Success Memory Item 1
## Title
Keyword-Driven Passage Filtering
## Description
Isolate core identifiers from descriptive prompts and use them to rapidly scan and filter retrieved documents for relevant evidence.
## Content
Break down trivia or definition-style questions into essential components such as brand names, ingredients, size descriptors, or cultural associations. Search the context specifically for these terms to bypass unrelated information and locate passages that directly address the query.

# Success Memory Item 2
## Title
Explicit Phrase Matching for Entity Identification
## Description
Align the question's descriptive attributes with direct statements in the context, treating co-occurring descriptors and candidate terms as definitive links.
## Content
When a passage explicitly pairs a known attribute with a specific noun, prioritize that connection. Rely on direct textual overlap rather than external knowledge or complex inference to identify the target entity.

# Success Memory Item 3
## Title
Precise Noun Extraction for Final Output
## Description
Once the target term is confirmed through contextual alignment, extract only the exact identifier without additional commentary or structural modification.
## Content
Factual queries demand concise responses. After verifying that the extracted term satisfies all key descriptors in the prompt, remove surrounding context, adjectives, or explanatory clauses. Deliver only the core entity name formatted according to instructions to ensure maximum accuracy and compliance.
