# Success Memory Item 1
## Title
Identify Missing Members of Defined Groups
## Description
When a question requests a missing element from a known triad, trinity, or classification, locate explicit enumerations in the context that list all members together.
## Content
Scan retrieved documents for structural keywords (e.g., "trinity", "triad", "consists of", "three forms"). Compare the enumerated list against the elements already provided in the prompt to isolate the missing term. Rely on direct textual matches rather than external knowledge or inference.

# Success Memory Item 2
## Title
Multi-Passage Consensus Alignment
## Description
Confirm the complete composition of a group by cross-referencing multiple context snippets that independently enumerate the same classification.
## Content
If several passages consistently list identical entities under the same category, treat this repeated enumeration as definitive. This approach resolves ambiguity, filters out partial lists, and ensures the extracted term belongs to the correct conceptual set.

# Success Memory Item 3
## Title
Direct Term Extraction with Strict Output Compliance
## Description
Isolate the exact target term from the confirmed list and format it according to instructions without adding explanatory text.
## Content
Once the missing entity is verified through context matching, extract only the precise name or phrase requested. Immediately wrap the result in the specified tags, ensuring the final output contains solely the answer to satisfy automated parsing requirements.
