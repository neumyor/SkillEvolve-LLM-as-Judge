# Success Memory Item 1
## Title
Temporal-Spatial Anchor Mapping
## Description
Use specific dates, locations, or event markers from the prompt to filter and locate the relevant information block in the retrieved context.
## Content
Identify unique constraints in the question, scan the context for matching phrases, and extract the associated subject or entity directly linked to those anchors.

# Success Memory Item 2
## Title
Canonical Term Extraction
## Description
Prioritize extracting the exact terminology used in the source documents over paraphrasing or inferring synonyms.
## Content
When the context explicitly names the target concept using standard phrasing, adopt that exact wording for the final answer to maximize alignment with expected responses.

# Success Memory Item 3
## Title
Multi-Snippet Convergence Confirmation
## Description
Confirm the selected answer appears consistently across multiple independent retrieved documents before finalizing.
## Content
Cross-reference several context snippets to ensure the identified term is repeatedly associated with the query's parameters, using this repetition as a signal to commit to the answer.
