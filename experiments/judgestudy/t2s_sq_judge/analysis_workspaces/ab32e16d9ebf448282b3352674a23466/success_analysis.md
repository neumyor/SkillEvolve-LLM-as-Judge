# Success Memory Item 1
## Title
Clue-Driven Lexical Mapping
## Description
Decompose the prompt into discrete constraints (part of speech, semantic definition, etymological roots) and cross-reference them against retrieved dictionary or etymology entries.
## Content
Extract each defining characteristic from the query and scan context snippets for explicit lexical entries that satisfy all conditions simultaneously. Prioritize sources that provide direct linguistic breakdowns or authoritative definitions over inferential reasoning, ensuring the selected term aligns perfectly with every stated constraint.

# Success Memory Item 2
## Title
Verbatim Phrasing Exploitation
## Description
Identify high-confidence answers by detecting exact or near-exact phrasing overlaps between the prompt and retrieved documents.
## Content
When prompts utilize distinctive quiz-style wording or specific descriptive phrases, search the context for matching strings. Documents containing these verbatim formulations typically house the direct answer, enabling rapid extraction without requiring complex synthesis or external knowledge retrieval.

# Success Memory Item 3
## Title
Constraint-Strict Output Isolation
## Description
Extract only the final target term and enclose it within the mandated delimiters, deliberately omitting all intermediate steps, citations, or explanatory text.
## Content
Once the correct term is validated through context matching, strip away reasoning traces, source references, and conversational framing. Output solely the raw answer string wrapped in the required tags to guarantee structural compliance and prevent parsing failures.
