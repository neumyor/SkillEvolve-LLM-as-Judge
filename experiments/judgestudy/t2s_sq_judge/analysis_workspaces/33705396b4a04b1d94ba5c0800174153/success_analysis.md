# Success Memory Item 1
## Title
Exact Phrase Anchoring
## Description
Leverage highly specific or verbatim phrasing in the prompt as direct search anchors within the retrieved context to rapidly isolate the relevant document.
## Content
When a question contains distinctive wording, quotes, or trivia-style clues, scan the context for an exact string match. This bypasses broad semantic searching and immediately points to the source passage containing the target information.

# Success Memory Item 2
## Title
Cross-Document Consistency Checking
## Description
Confirm the identified entity by correlating the matched phrase with independent contextual details across multiple documents.
## Content
After locating a verbatim match, evaluate the subject by checking other retrieved passages for consistent factual markers (e.g., dates, locations, professions). This ensures accurate entity resolution and prevents misattribution when similar phrases appear in unrelated contexts.

# Success Memory Item 3
## Title
Declarative Prompt Rephrasing
## Description
Convert trivia-style or quote-based questions into declarative statements to streamline entity extraction from contextual matches.
## Content
Treat the prompt as a factual claim rather than an interrogative sentence. Once the corresponding context is located, extract the associated proper noun directly from the surrounding text, aligning the statement's subject with the required answer format.
