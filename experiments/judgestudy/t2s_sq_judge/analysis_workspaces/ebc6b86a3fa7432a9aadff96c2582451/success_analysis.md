# Success Memory Item 1
## Title
Definitional Phrase Matching
## Description
Locate explicit definitional statements in the context that directly correspond to the scenario described in the prompt.
## Content
When the query asks for a specific term or phrase based on a description, scan retrieved documents for glossary-style entries, dictionary definitions, or statutory language. Match the prompt's key descriptors to the defining sentence to extract the exact target term.

# Success Memory Item 2
## Title
Reference Source Prioritization
## Description
Elevate reference materials, legal texts, and vocabulary lists above narrative reports when seeking precise terminology.
## Content
Narrative articles often describe isolated incidents without naming the underlying concept. Prioritize contexts that function as reference guides or legal frameworks, as they are structured to explicitly name and define the terms being queried.

# Success Memory Item 3
## Title
Strict Format Compliance
## Description
Extract the identified term and immediately wrap it in the required output tags, omitting all intermediate reasoning.
## Content
Once the correct term is confirmed via contextual matching, bypass explanatory text. Apply the exact formatting constraint specified in the prompt to the final answer. This prevents format violations and ensures direct compliance with evaluation metrics.
