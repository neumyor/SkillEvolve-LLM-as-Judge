# Success Memory Item 1
## Title
Direct Semantic Mapping
## Description
Resolve definition-based or etymological clues by locating explicit textual equivalences in the retrieved context.
## Content
When a prompt specifies a meaning, translation, or literal definition, scan the context for sentences that directly equate a candidate term with that description. Prioritize passages containing explicit glosses or dictionary-style definitions over implicit associations.

# Success Memory Item 2
## Title
Constraint-Aligned Extraction
## Description
Isolate the target entity by cross-referencing semantic matches with categorical constraints specified in the prompt.
## Content
After identifying terms that satisfy the semantic clue, filter them against additional prompt requirements such as nationality, object type, or historical period. Select only the term that simultaneously fulfills both the descriptive clue and the categorical boundaries.

# Success Memory Item 3
## Title
Instruction-Compliant Formatting
## Description
Deliver the final response using strict adherence to output specifications while maintaining minimalism.
## Content
Once the target term is isolated, wrap it in the required tags and submit it directly. Omit reasoning steps, contextual summaries, or alternative candidates to ensure the output precisely matches the requested format and length constraints.
