# Success Memory Item 1
## Title
Anchor Retrieval on Creative Works
## Description
Use referenced titles and creators as primary search anchors to locate the target entity.
## Content
When a query cites a specific play, film, or song, prioritize documents that explicitly link that title to its creator. Treat the work as a factual bridge to the subject, then scan surrounding text for biographical details or thematic connections that point to the individual in question.

# Success Memory Item 2
## Title
Semantic Mapping of Descriptive Clues
## Description
Translate stylized or trivia-style phrasing into concrete attributes present in the context.
## Content
Break down abstract or period-specific descriptors (e.g., "diva of the double entendre") into searchable semantic equivalents. Cross-reference these mapped traits against explicit statements in the retrieved documents to verify that multiple distinct characteristics align with a single candidate.

# Success Memory Item 3
## Title
Direct Entity Extraction & Formatting
## Description
Output the confirmed name immediately upon trait alignment, adhering strictly to structural requirements.
## Content
Once contextual evidence consistently supports one entity, extract only the precise proper noun. Omit explanatory text or hedging language. Apply the exact output wrapper requested by the prompt to ensure compliance with automated evaluation metrics.
