# Success Memory Item 1
## Title
Map Descriptive Clues to Defined Terms
## Description
Translate event descriptions in the prompt into the exact terminology used in the context.
## Content
When a question describes a phenomenon (e.g., "passing in front of the sun"), scan the context for the formal label assigned to that action. Extract the precise noun phrase rather than generating synonyms or explanations.

# Success Memory Item 2
## Title
Cross-Reference Consistent Definitions
## Description
Establish the target term as the standard designation by checking its presence across multiple context snippets.
## Content
Look for repeated usage of the same term across different retrieved documents. When multiple sources independently apply the identical label to the queried scenario, adopt it as the definitive answer without modification.

# Success Memory Item 3
## Title
Output Minimalist Answers for Direct Queries
## Description
Strip explanatory context and return only the core requested term to satisfy direct factual prompts.
## Content
Recognize trivia-style or definition-seeking questions that ask for a specific name. Discard surrounding narrative, dates, or comparisons from the final output. Provide only the exact term requested, formatted within the designated tags.
