# Success Memory Item 1
## Title
Dual-Constraint Lexical Matching
## Description
Resolve trivia or definition queries by cross-referencing explicit etymological markers with semantic synonyms in retrieved reference material.
## Content
When a prompt provides both a historical language derivation and a contemporary equivalent, filter retrieved dictionary or etymology entries to find the single headword that explicitly links both constraints. Prioritize snippets containing direct quotes or translations of the origin phrase alongside the target definition, then extract the corresponding term as the definitive answer.
