# Success Memory Item 1
## Title
Constraint-to-Entity Mapping via Cross-Document Alignment
## Description
Apply when answering factual identification questions that provide specific temporal, numerical, or policy-based constraints requiring retrieval of a target entity (e.g., country, organization, individual).
## Content
1. Extract explicit constraints from the prompt (dates, policy names, limits, or distinctive conditions).
2. Scan retrieved snippets for direct lexical or semantic matches to each constraint.
3. Identify the recurring target entity consistently linked to all matched constraints across multiple independent documents.
4. Validate that the entity's documented attributes fully align with every constraint before finalizing the response.
5. Immediately apply required output formatting upon confirmation.
