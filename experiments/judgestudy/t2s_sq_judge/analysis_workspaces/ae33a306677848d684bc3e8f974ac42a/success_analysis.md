# Success Memory Item 1
## Title
Constraint Decomposition & Metadata Alignment
## Description
Break down descriptive prompts into discrete factual anchors to systematically filter retrieved documents.
## Content
Extract explicit keywords, names, durations, and setting details from the query. Cross-reference these anchors against document titles, cast/crew lists, and plot summaries to isolate the most relevant source before synthesizing a response.

# Success Memory Item 2
## Title
Referential Phrasing Interpretation
## Description
Use demonstrative cues and contextual hints to determine whether the answer targets the main entity or a specific component.
## Content
Analyze phrases like "trapped in one of these" to identify if the prompt points to a physical object, concept, or the broader work itself. Align the final answer precisely with the referent indicated by the wording rather than defaulting to the primary subject.

# Success Memory Item 3
## Title
Precision Output Formatting
## Description
Reduce identified matches to their core noun phrase and apply strict structural wrappers.
## Content
Once the correct entity is isolated, strip all narrative explanation and deliver only the exact term requested. Wrap the concise answer in the required tags to ensure immediate parsing and compliance with output constraints.
