# Success Memory Item 1
## Title
Resolve Colloquialisms and Nicknames via Contextual Cross-Reference
## Description
Map informal terms, slogans, or cultural references to their formal identifiers by locating explicit pairings within the retrieved text.
## Content
Extract the informal phrase from the prompt. Scan context snippets for direct associations linking that phrase to a full name or official title. Rely solely on these explicit textual connections to establish identity, bypassing assumptions or external knowledge.

# Success Memory Item 2
## Title
Anchor Retrieval with Temporal and Thematic Keywords
## Description
Use specific timeframes, object types, or event markers from the question to rapidly filter relevant context and discard unrelated material.
## Content
Identify constraints like decades, mediums, or catchphrases in the query. Match these against document titles and excerpts to pinpoint passages discussing the exact era or artifact. Treat these anchored snippets as the primary evidence base for answering.

# Success Memory Item 3
## Title
Isolate and Format the Target Entity Directly
## Description
Once the correct entity is confirmed, strip away all surrounding narrative and output only the precise answer in the required structure.
## Content
After verifying the entity through context matching, ignore promotional text, biographical details, or tangential facts. Extract only the verified name or value and place it strictly inside the designated answer tags, maintaining exact compliance with formatting rules.
