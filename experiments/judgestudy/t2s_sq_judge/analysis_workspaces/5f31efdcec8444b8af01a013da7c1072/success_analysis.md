# Success Memory Item 1
## Title
Constraint Decomposition for Multi-Clue Queries
## Description
Isolate discrete factual attributes from complex prompts to guide targeted context scanning.
## Content
When processing trivia or factoid questions containing multiple specific details (e.g., temporal markers, performer names, roles, and creative contributions), explicitly extract each constraint before reviewing retrieved documents. Map these isolated attributes directly to passage content to rapidly identify the target entity and filter out tangential information.

# Success Memory Item 2
## Title
Direct Phrasing Alignment & Cross-Source Convergence
## Description
Prioritize passages that mirror prompt syntax and leverage consistent signals across multiple documents.
## Content
Scan retrieved context for exact keyword overlaps or structural similarities to the original question. When multiple independent sources independently confirm the same entity and attributes, treat this convergence as high-confidence evidence. Relying on direct textual alignment and source agreement reduces inference overhead and accelerates decision-making.

# Success Memory Item 3
## Format-First Execution Protocol
## Description
Internalize structural requirements during the reasoning phase to guarantee compliant output generation.
## Content
Before synthesizing the final response, explicitly acknowledge all formatting directives (e.g., specific delimiters, length constraints, or ordering rules). Structure the step-by-step reasoning to naturally culminate in the mandated output wrapper, ensuring seamless compliance without requiring post-generation editing.
