# Success Memory Item 1
## Title
Keyword-Driven Entity Extraction
## Description
Rapidly isolate target entities by mapping unique query parameters directly to explicit contextual statements.
## Content
When a prompt supplies highly specific identifiers (e.g., dates, quantities, equipment types), scan retrieved documents for exact keyword overlaps. Extract the named entity directly from sentences that explicitly link those identifiers to a subject, avoiding unnecessary inference or background synthesis.

# Success Memory Item 2
## Title
Cross-Source Convergence Assessment
## Description
Leverage agreement across multiple independent context snippets to solidify answer selection.
## Content
If several retrieved passages independently reference the same entity using consistent terminology, treat this convergence as sufficient grounds for selection. Prioritizing answers that appear across different sources minimizes reliance on ambiguous single-document phrasing and strengthens extraction confidence.

# Success Memory Item 3
## Title
Strict Delimiter Enforcement
## Description
Apply required output formatting immediately upon answer identification to guarantee structural compliance.
## Content
Once the target answer is confirmed, wrap it precisely within the specified tags without appending conversational filler or step-by-step explanations. Maintain a clean boundary between internal reasoning and the final structured output to satisfy automated parsing requirements.
