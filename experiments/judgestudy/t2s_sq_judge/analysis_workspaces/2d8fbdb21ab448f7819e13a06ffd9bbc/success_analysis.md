# Success Memory Item 1
## Title
Keyword-Driven Context Scanning
## Description
Map distinctive phrases from the prompt directly onto retrieved documents to locate the relevant information efficiently.
## Content
Extract unique descriptors, actions, or historical claims from the question and search for their exact or near-exact matches in the provided text. This bypasses irrelevant sections and rapidly isolates the passage containing the answer.

# Success Memory Item 2
## Title
Cross-Doc Alignment Confirmation
## Description
Leverage repeated explicit statements across different documents to solidify the target entity before responding.
## Content
When multiple retrieved sources independently state the same fact using identical phrasing, treat this repetition as strong contextual evidence. Prioritize extracting the answer directly from these aligned passages rather than synthesizing or inferring from fragmented data.

# Success Memory Item 3
## Title
Direct Entity Extraction & Format Compliance
## Description
Isolate the precise target term from the matched text and apply strict output formatting without elaboration.
## Content
Once the relevant passage is identified, extract only the specific noun or phrase that fulfills the query. Immediately wrap it in the required tags, ensuring the response remains concise and strictly adheres to structural constraints.
