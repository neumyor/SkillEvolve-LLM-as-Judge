# Success Memory Item 1
## Title
Enumerate Candidates and Compare Target Attributes
## Description
When identifying an extreme within a defined set, explicitly list all valid members first, then evaluate each against the specific criterion requested.
## Content
Extract the complete set of eligible entities from the prompt or retrieved context. Systematically assess each entity against the exact attribute specified in the question (e.g., physical dimension, weight, frequency). Select the item that strictly satisfies the maximum or minimum condition without assuming implicit rankings.

# Success Memory Item 2
## Title
Disambiguate Physical Metrics from Nominal Values
## Description
Questions targeting physical or structural extremes often conflate magnitude with intrinsic worth or denomination. Separate the requested measurement from related but distinct properties before evaluating candidates.
## Content
Parse the question carefully to distinguish between quantitative/value-based descriptors (e.g., lowest price, highest denomination) and physical/structural descriptors (e.g., smallest diameter, lightest weight). Apply the correct filter to eliminate candidates that match the wrong attribute type, preventing common semantic traps.

# Success Memory Item 3
## Title
Scope-Bound Retrieval with Factual Resolution
## Description
Use retrieved documents to establish the valid candidate pool, then bridge gaps in comparative data using established domain knowledge to determine the specific ranking or attribute.
## Content
If context confirms the category or list of relevant items but lacks direct comparative metrics, rely on the retrieved scope to define eligibility. Apply precise external knowledge to rank or measure the items against the target attribute, ensuring the final selection aligns with both the contextual boundaries and the question's exact phrasing.
