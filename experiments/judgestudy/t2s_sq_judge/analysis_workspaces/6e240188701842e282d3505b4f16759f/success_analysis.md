# Success Memory Item 1
## Title
Direct String Matching for Trivia and Quiz Prompts
## Description
Leverage exact or near-exact phrase overlap between the prompt and retrieved context to rapidly locate answers in trivia, Jeopardy, or quiz-style questions.
## Content
1. Scan retrieved passages for verbatim or highly similar phrasing of the original question.
2. Identify the target answer term positioned immediately adjacent to or following the matched query text.
3. Extract the identified term and ensure it semantically completes the prompt's statement.
4. Format the extracted term directly into the required response structure.
