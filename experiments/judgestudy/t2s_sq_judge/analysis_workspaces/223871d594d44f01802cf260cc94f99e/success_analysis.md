# Success Memory Item 1
## Title
Resolve Colloquial Aliases via Explicit Contextual Links
## Description
Identify the target entity by locating direct statements in the context that equate a given nickname or alternative name with its common term.
## Content
When a query references an object using a cultural nickname, slang, or historical alias, search the provided text for explicit equivalence phrases like "also known as," "referred to as," or "called." Extract the primary subject linked to that alias as the definitive answer.

# Success Memory Item 2
## Title
Validate Consistency Across Multiple Snippets
## Description
Confirm the identified entity appears consistently across different retrieved documents to rule out ambiguity or contextual mismatch.
## Content
Before finalizing, verify that multiple independent context passages point to the same core term. This cross-check minimizes false positives from tangentially related topics and ensures the selected answer is robustly supported by the evidence pool.

# Success Memory Item 3
## Title
Extract Core Noun Phrases with Strict Tagging
## Description
Isolate the exact subject phrase answering the prompt and format it precisely within the required output boundaries.
## Content
Strip away descriptive clauses, procedural details, or secondary context to return only the fundamental entity name. Ensure the final output strictly adheres to the specified tag structure without additional conversational filler or explanatory text.
