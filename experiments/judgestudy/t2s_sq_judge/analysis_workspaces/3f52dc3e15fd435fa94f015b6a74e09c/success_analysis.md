# Success Memory Item 1
## Title
Attribute-to-Entity Mapping
## Description
Extract the target concept by systematically aligning specific descriptive clues in the query with matching factual statements across retrieved documents.
## Content
Isolate key modifiers in the question (e.g., cause, magnitude, speed, behavior). Scan all context snippets for explicit mentions of these attributes. Identify the consistent subject noun that serves as the direct referent for the combined clues. Validate by checking that multiple independent sources link the same term to the described attributes. Output only the extracted term, strictly adhering to the prescribed response format.
