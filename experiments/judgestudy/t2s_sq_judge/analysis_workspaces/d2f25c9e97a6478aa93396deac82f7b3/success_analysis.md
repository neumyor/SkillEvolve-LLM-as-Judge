# Success Memory Item 1
## Title
Descriptive-to-Textual Mapping
## Description
Align unique query descriptors with explicit contextual phrases to pinpoint the target entity.
## Content
Isolate distinctive attributes in the prompt (e.g., color, action, source material) and scan the retrieved context for direct lexical or semantic matches. Use these overlapping phrases to confidently extract the specific entity requested.

# Success Memory Item 2
## Title
Contextual Confirmation
## Description
Cross-reference the candidate answer against the most direct contextual statement before finalizing.
## Content
Locate the clearest supporting sentence in the context that mirrors the prompt's conditions. Ensure the match fully addresses the query, preferring the simplest accurate form that satisfies all constraints without unnecessary modification.

# Success Memory Item 3
## Title
Constraint-Driven Formatting
## Description
Apply the required output structure immediately after confirmation to ensure strict compliance.
## Content
Once the answer is confirmed against the context, wrap it precisely in the specified tags or format. Omit supplementary explanations or conversational filler to maintain focus on the exact requested output.
