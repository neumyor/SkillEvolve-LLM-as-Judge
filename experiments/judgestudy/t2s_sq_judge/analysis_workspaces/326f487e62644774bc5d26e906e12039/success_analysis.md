# Success Memory Item 1
## Title
Attribute-Constraint Entity Matching
## Description
Resolve factoid queries by aligning explicit prompt descriptors with concurrent factual claims in retrieved text.
## Content
Decompose the question into distinct identifying constraints (e.g., professional role, creative credit, associated work). Scan the context for passages that explicitly pair these constraints with a single named entity. When multiple retrieved snippets independently confirm the same entity-constraint mapping, extract the entity directly and output it concisely within the required formatting tags.
