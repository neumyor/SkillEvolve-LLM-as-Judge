# Success Memory Item 1
## Title
Slogan and Tagline Entity Mapping
## Description
Leverage distinctive quotes, marketing phrases, or taglines in the prompt as direct anchors to identify the target entity within the retrieved context.
## Content
When a question features a unique or branded phrase, search for that exact string in the context rather than relying solely on keyword overlap. Once located, extract the immediately associated entity name (e.g., company, organization, or product) as the answer. This approach bypasses unnecessary inference by treating recognized slogans as explicit contextual identifiers.
