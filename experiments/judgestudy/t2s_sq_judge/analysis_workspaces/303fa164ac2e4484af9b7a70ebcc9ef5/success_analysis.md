# Success Memory Item 1
## Title
Verbatim Context Matching for Definitional Prompts
## Description
When the prompt is a short definition, clue, or trivia statement, prioritize scanning retrieved documents for exact or near-exact phrase overlaps to surface the target term.
## Content
Definitional queries are frequently extracted directly from reference materials. A quick lexical scan for verbatim matches between the prompt and context often yields the correct answer without requiring multi-step reasoning, significantly reducing search overhead.

# Success Memory Item 2
## Title
Cross-Source Definition Disambiguation
## Description
Validate a candidate answer by comparing its explicit definition across multiple context types (e.g., dictionaries, archives, encyclopedias) to ensure strict semantic alignment with the prompt.
## Content
Synonyms or closely related concepts often appear in search results. By checking how different sources define each candidate, the agent can eliminate terms that share surface similarity but lack the precise contextual equivalence required by the prompt.

# Success Memory Item 3
## Title
Query Genre & Source Pattern Recognition
## Description
Identify the structural style of the prompt (e.g., quiz show clue, dictionary entry, technical glossary) to filter and prioritize context snippets that originate from matching formats.
## Content: Recognizing the prompt's genre allows the agent to weight context relevance appropriately. Snippets that mirror the prompt's format (such as archive logs for trivia clues or thesaurus entries for vocabulary) carry higher predictive value for accurate term extraction.
