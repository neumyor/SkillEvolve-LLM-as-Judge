# Success Memory Item 1
## Title
Explicit Link Extraction for Type/Category Questions
## Description
For questions asking which broader category or type specific named entities represent, locate and extract the exact category term from contextual sentences that directly pair those entities together.
## Content
Search retrieved passages for syntactic patterns that group the query entities alongside a shared classification noun (e.g., "X and Y produce/supply [Category]" or "varieties of [Category]"). Prioritize exact phrasing over fragmented or indirect mentions. Once the linking statement is identified, isolate the target category term, verify it aligns with the question's grammatical frame, and output it directly without additional inference.
