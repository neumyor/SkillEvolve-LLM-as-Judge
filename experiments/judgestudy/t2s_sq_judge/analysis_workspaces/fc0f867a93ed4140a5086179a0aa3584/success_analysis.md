# Success Memory Item 1
## Title
Keyword-Driven Context Scanning
## Description
Systematically extract core terms from the prompt and scan retrieved passages for direct matches to isolate relevant evidence.
## Content
Identify key nouns, verbs, and descriptors in the question. Filter through all provided snippets by searching specifically for these terms, allowing you to quickly pinpoint the exact location of the answer while disregarding tangential or unrelated document content.

# Success Memory Item 2
## Title
Multi-Passage Entity Corroboration
## Description
Aggregate consistent references across multiple context snippets to confidently verify the primary subject or entity.
## Content
When a single passage is ambiguous or fragmented, cross-reference how different documents attribute the target phrase. Repeated association of the key concept with one specific person or entity provides high-confidence validation without requiring external knowledge.

# Success Memory Item 3
## Title
Constraint-Aligned Direct Extraction
## Description
Derive the final answer strictly from verified context spans, stripping away explanation to meet precise formatting rules.
## Content
Once the correct entity is confirmed, reduce it to its simplest, most direct form. Omit supplementary details, avoid introducing outside facts, and place the concise result strictly within the mandated output tags to satisfy evaluation metrics.
