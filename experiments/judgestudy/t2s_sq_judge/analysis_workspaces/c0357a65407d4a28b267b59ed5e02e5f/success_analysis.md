# Success Memory Item 1
## Title
Direct Phrase-to-Entity Mapping for Clue-Based Questions
## Description
Identify target answers by locating exact textual overlaps between the prompt and retrieved context snippets.
## Content
When a question uses distinctive, verbatim phrasing (common in quiz, Jeopardy, or flashcard formats), search the retrieved context for identical strings. The named entity directly associated with these matching phrases is typically the correct answer. Extract this entity immediately without additional synthesis, as the retrieval system has already aligned the clue with its corresponding fact.
