# Success Memory Item 1
## Title
Prioritize Direct Keyword Co-occurrence
## Description
Scan retrieved documents for passages where the prompt's core terms appear together or in immediate proximity, rather than independently across unrelated contexts.
## Content
When a question combines a noun with a specific descriptor, filter results to only consider snippets where both elements are explicitly linked. Discard documents where the terms appear separately or in metaphorical, scientific, or narrative contexts that do not establish a direct relationship.

# Success Memory Item 2
## Title
Resolve Polysemy via Functional Pairing
## Description
Identify the standard functional relationship between a tool or object and the material it interacts with, using the prompt's clues to eliminate homonyms or unrelated domains.
## Content
Questions referencing instruments often imply a practical use case. Match the named item against the described material property to isolate the correct category (e.g., kitchenware vs. astronomy vs. fiction). Prioritize contexts that describe actual usage or physical interaction over abstract or figurative mentions.

# Success Memory Item 3
## Title
Align Prompt Descriptors with Textual Phrases
## Description
Treat specific adjectives or nouns in the question as direct pointers to exact or near-exact phrase matches in the retrieved context.
## Content
Use precise wording overlap to confirm the intended referent. When a prompt specifies a characteristic like "sticky substance," actively look for corresponding phrases in the text (e.g., "sticky [material]"). This lexical alignment quickly narrows down candidates and validates the correct answer without external assumptions.
