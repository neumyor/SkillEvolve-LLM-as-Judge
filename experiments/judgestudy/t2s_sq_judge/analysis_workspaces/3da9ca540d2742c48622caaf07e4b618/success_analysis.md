# Success Memory Item 1
## Title
Geographic Container Mapping via Landmark-Reference Pairing
## Description
Resolve location-based questions by linking a specific landmark to its mentioned reference point to identify the encompassing administrative region.
## Content
Extract the primary subject and its associated reference location from the query. Scan retrieved context for explicit geographic tags, directional phrases, or proximity statements that connect both entities to a broader region (e.g., state or country). When the context directly names the region alongside these landmarks, extract it immediately without additional inference.

# Success Memory Item 2
## Title
Cross-Snippet Alignment Check
## Description
Ensure contextual consistency by confirming multiple independent passages align on the same extracted detail.
## Content
When several documents address overlapping query components, compare their geographic or factual claims. Prioritize answers that appear consistently across different snippets, as repeated contextual alignment indicates a reliable match and minimizes the risk of selecting an out-of-context or tangential mention.

# Success Memory Item 3
## Title
Verbatim Extraction for Direct Facts
## Description
Maintain precision in factual responses by prioritizing exact contextual phrasing over synthesis or paraphrasing.
## Content
For straightforward location or definition queries, locate the precise sentence containing the requested information. Extract the relevant term or phrase exactly as written in the source material, ensuring strict compliance with output formatting rules while avoiding unnecessary elaboration or assumption.
