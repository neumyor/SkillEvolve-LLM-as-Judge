# Success Memory Item 1
## Title
Multi-Source Cross-Referencing
## Description
Confirm factual answers by identifying consistent mentions across multiple retrieved documents before extraction.
## Content
Scan all context snippets for the target entity. Require agreement from at least two independent sources to establish confidence, filtering out isolated or ambiguous claims before proceeding to answer generation.

# Success Memory Item 2
## Title
Direct Entity Mapping
## Description
Extract the precise noun or phrase requested, bypassing paraphrasing or contextual elaboration.
## Content
Align question keywords directly with the corresponding term in the text. Output only the exact entity (e.g., instrument, title, name) to maximize lexical overlap with expected answers and avoid unnecessary verbosity.

# Success Memory Item 3
## Title
Constraint-Compliant Tagging
## Description
Format the final output strictly according to prompt specifications, isolating the answer within designated markers.
## Content
Wrap the extracted entity exclusively in the required tags. Omit all reasoning steps, introductory text, or supplementary explanations in the final response block to ensure clean machine parsing and compliance.
