# Success Memory Item 1
## Title
Direct Definitional Phrase Matching
## Description
Align descriptive phrases in the question with explicit definitional statements in the context to identify the target term.
## Content
When a question describes a concept, method, or field using a specific phrase, scan the retrieved context for sentences that directly define or name that concept. Prioritize contexts where the target term appears adjacent to or immediately preceding the descriptive phrase, as this structural cue often indicates a direct match.

# Success Memory Item 2
## Title
Temporal and Descriptive Anchor Filtering
## Description
Use specific time markers and functional characteristics from the prompt to narrow down candidate entities in the context.
## Content
Extract concrete constraints from the question, such as historical periods and operational details. Cross-reference these anchors against the context to filter out irrelevant topics. Entities that satisfy both the temporal and functional constraints are highly likely to be the correct answer.

# Success Memory Item 3
## Title
Cross-Document Consensus Validation
## Description
Confirm the target answer by verifying its consistent appearance across multiple independent context snippets.
## Content
If multiple retrieved documents independently mention the same core facts, pioneers, or definitions related to the question, treat this convergence as strong evidence for the correct term. Use this consistency to confidently select the primary term over minor variations or related concepts mentioned in isolated snippets.
