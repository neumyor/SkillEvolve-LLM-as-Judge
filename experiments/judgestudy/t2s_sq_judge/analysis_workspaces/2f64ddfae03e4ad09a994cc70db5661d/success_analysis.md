# Success Memory Item 1
## Title
Direct Evidence Extraction with Constraint Matching
## Description
Identify explicit statements in retrieved text that address the query's core subject, then cross-check the stated detail against the question's specific parameters to confirm the correct entity.
## Content
In retrieval-augmented QA, prioritize passages containing direct mentions of the key terms and the described phenomenon. Once a relevant snippet is found, quickly assess whether the mentioned detail satisfies all specific constraints in the prompt (such as character counts, structural changes, or named attributes). This immediate alignment check filters out tangential information and enables precise extraction of the target answer directly from the confirmed context.
