# Success Memory Item 1
## Title
Recurring Term Mapping for Foundational Components
## Description
Identify the core element of a queried subject by tracking which ingredients or components are repeatedly paired with the target names across the context.
## Content
When processing queries about recipes, formulations, or systems, scan the retrieved text for consistent co-occurrences between the subject and specific components. Prioritize terms that appear alongside the target names in multiple passages, as recurrence strongly indicates the primary foundation rather than incidental additives.

# Success Memory Item 2
## Title
Cross-Source Corroboration
## Description
Strengthen confidence in a selected answer by confirming its independent appearance across distinct context documents.
## Content
Instead of relying on a single passage, check whether multiple unrelated sources within the context independently reference the same component for the queried subject. Consistent cross-document alignment filters out outlier mentions, recipe variations, or tangential discussions, isolating the most reliable answer.

# Success Memory Item 3
## Title
Context-Anchored Disambiguation
## Description
Resolve vague or dual-nature descriptors in prompts by restricting interpretation to what the context explicitly highlights.
## Content
For questions containing ambiguous qualifiers or categorical hints, use established domain knowledge to frame possibilities but anchor the final selection strictly to the most frequently cited term in the retrieved material. Let the context dictate the precise terminology while using external knowledge only to bridge semantic gaps in the prompt.
