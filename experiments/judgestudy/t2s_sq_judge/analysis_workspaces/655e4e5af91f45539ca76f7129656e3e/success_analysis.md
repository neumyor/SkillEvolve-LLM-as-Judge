# Success Memory Item 1
## Title
Direct Phrasing Alignment for Terminology Extraction
## Description
Match question syntax to explicit contextual statements to extract missing terms.
## Content
For fill-in-the-blank or specific-term questions, scan retrieved documents for sentences that structurally mirror the prompt. Identify contexts that explicitly state conditions, definitions, or mechanisms. Extract the exact term filling the placeholder directly from these matching statements, prioritizing verbatim contextual evidence over inference.
