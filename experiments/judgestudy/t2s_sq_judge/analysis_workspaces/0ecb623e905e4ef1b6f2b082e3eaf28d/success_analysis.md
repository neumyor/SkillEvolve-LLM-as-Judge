# Success Memory Item 1
## Title
Interpret Descriptive Clues as Term Identification Tasks
## Description
Recognize when prompts are phrased as statements or Jeopardy-style clues rather than direct questions, and map them to identifying the underlying concept.
## Content
Treat descriptive prompts (e.g., "This term for X originated in Y during Z") as requests to identify the specific term. Extract key constraints from the prompt (definition, domain, timeframe) and search the context for a direct match, ignoring syntactic variations in the question phrasing.

# Success Memory Item 2
## Title
Multi-Constraint Verification Before Answer Extraction
## Description
Validate candidate answers by checking alignment across all explicit details provided in the prompt.
## Content
Do not rely on a single keyword match. Cross-reference every detail in the prompt (e.g., symptom type, sport, decade) against the retrieved context to confirm the correct entity. This prevents misattribution when multiple terms share partial similarities.

# Success Memory Item 3
## Title
Standardize Output Using Contextual Primacy
## Description
Select the most canonical or frequently cited variant when the context acknowledges multiple acceptable forms.
## Content
If the context lists alternative spellings or names, prioritize the primary or most commonly referenced form for the final answer. Keep the output concise and strictly within the required tags, avoiding unnecessary qualifiers unless specified.
