# Success Memory Item 1
## Title
Exact Phrase Co-occurrence for Nickname Resolution
## Description
Resolve quoted epithets, slogans, or distinctive descriptive tags by locating the verbatim string in the retrieved context and extracting its direct syntactic referent.
## Content
Scan the provided context for the exact quoted phrase from the prompt rather than searching for conceptual synonyms or related keywords. Once located, identify the immediately adjacent proper noun, character name, or subject that serves as the grammatical referent. Output only this extracted entity without inference, elaboration, or external knowledge. This method efficiently handles trivia-style prompts that function as direct catchphrase or marketing-description lookups.
