# Success Memory Item 1
## Title
Cross-Document Pattern Matching for Shared Terms
## Description
Resolve incomplete queries, riddles, or trivia clues by identifying the common lexical link across multiple contextual references.
## Content
When a prompt presents a partial phrase, categorical hint, or trivia clue referencing multiple specific examples, avoid searching for a single exact match. Instead, scan all retrieved documents for complete instances of each referenced example. Extract the recurring word, suffix, prefix, or category that consistently appears alongside them. Treat the distributed textual fragments as complementary pieces of a single conceptual puzzle, and use the identified shared element to formulate the final answer.
