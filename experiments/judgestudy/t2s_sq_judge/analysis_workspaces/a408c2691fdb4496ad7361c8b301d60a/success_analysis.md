# Success Memory Item 1
## Title
Targeted Descriptor Mapping
## Description
Isolate key physical, behavioral, or taxonomic phrases from the prompt and scan the retrieved context for exact or near-exact matches to rapidly narrow down the target entity.
## Content
When answering definitional or descriptive queries, break the question into its core identifying attributes. Directly search the context for sentences containing these attributes simultaneously. Documents that explicitly pair the prompt's specific descriptors (e.g., morphology, habitat, behavior) provide the strongest signal for the correct subject, allowing you to bypass irrelevant or tangential information.

# Success Memory Item 2
## Title
Cross-Source Convergence Validation
## Description
Use redundant mentions across multiple independent context passages to reinforce entity identification without requiring external fact-checking.
## Content
If several distinct documents in the retrieved set independently describe the same organism or object using matching criteria, treat this pattern as reliable confirmation. Prioritize the core identifier that appears consistently across sources. Disregard minor contextual variations or supplementary details that do not contradict the primary match, as convergence naturally filters out noise and isolated inaccuracies.

# Success Memory Item 3
## Title
Prompt-Aligned Terminology Selection
## Description
Select the final answer label that best matches the scope, phrasing, and expected granularity of the original question rather than defaulting to the most technical or verbose option.
## Content
When context offers both a general category and a specific common/scientific name, evaluate which term directly satisfies the prompt's framing. For straightforward descriptive or trivia-style questions, favor the most concise, widely recognized term that fully captures the described features. Align your output length and specificity with the linguistic style of the query to maximize compatibility with standard evaluation metrics.
