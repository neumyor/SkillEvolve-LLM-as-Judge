# Success Memory Item 1
## Title
Resolve Implicit Interrogatives in Declarative Prompts
## Description
Identify the missing question word when a prompt is structured as a factual statement rather than a direct query, and target the corresponding semantic role.
## Content
Analyze the sentence structure to determine whether the prompt implies a "who," "what," or "when" inquiry. Map the declarative clause to its logical missing component and extract the primary entity fulfilling that role.

# Success Memory Item 2
## Title
Disambiguate Roles Using Possessive and Subject Markers
## Description
Distinguish between closely related entities by analyzing pronoun usage and possessive phrasing within the prompt.
## Content
Phrases indicating personal ownership or agency signal that the query targets the original creator rather than a commercial distributor. Align the extracted answer with the grammatical subject performing the creative act.

# Success Memory Item 3
## Title
Triangulate Facts Across Independent Context Snippets
## Description
Strengthen answer confidence by checking that multiple retrieved documents independently report the same entity-action-date relationship.
## Content
When several distinct context passages converge on identical biographical details, treat this consistency as sufficient grounding for the final output. Prioritize answers that are repeatedly corroborated across different sources to establish reliable conclusions.
