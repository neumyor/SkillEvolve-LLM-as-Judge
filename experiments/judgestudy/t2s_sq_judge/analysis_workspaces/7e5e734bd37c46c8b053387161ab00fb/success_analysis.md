# Success Memory Item 1
## Title
Fraction-to-Percentage Conversion for Query Alignment
## Description
Translate fractional or proportional phrases in the prompt into approximate decimal/percentage values to establish a clear numerical target for retrieval analysis.
## Content
When a question uses terms like "about 1/5," "nearly half," or "roughly one-third," immediately convert them to their percentage equivalents (e.g., 20%, 50%, 33%) to create a precise search parameter for scanning the context.

# Success Memory Item 2
## Title
Targeted Statistical Extraction
## Description
Focus document scanning on quantitative claims tied directly to the query's subject, prioritizing explicit percentages, ratios, or demographic breakdowns.
## Content
Instead of reading passages linearly, actively filter for sentences containing numerical data associated with the key entities. Extract only the relevant statistics that quantify the subject's proportion, size, or frequency within the specified scope.

# Success Memory Item 3
## Title
Approximation Matching and Alternative Ruling
## Description
Identify the extracted value that most closely aligns with the converted target, while explicitly checking nearby figures to confirm the best fit.
## Content
Compare all candidate numbers against the target percentage. Select the value that falls within a reasonable margin of approximation (typically ±2-5%). Briefly verify that other prominent figures in the context do not offer a closer match before finalizing the selection.
