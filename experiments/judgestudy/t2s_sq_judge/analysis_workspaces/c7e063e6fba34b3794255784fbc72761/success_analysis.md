# Success Memory Item 1
## Title
Contextual Entity-Work Mapping
## Description
Extract target entities by linking descriptive identifiers to specific works or publications found in retrieved documents.
## Content
When a question pairs a descriptive role or attribute with a known title or publication, locate that exact title within the context. Identify the primary person or entity explicitly named alongside the work in the surrounding text. Ensure the extracted name corresponds to the descriptive identifier stated in the prompt, then output the result directly.
