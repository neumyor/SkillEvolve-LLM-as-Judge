# Success Memory Item 1
## Title
Keyword-Aligned Fact Extraction with Cross-Snippet Confirmation
## Description
Locate the target answer by matching prompt keywords against context snippets, then confirm the exact phrasing through consistent mentions across multiple documents before direct extraction.
## Content
Scan the retrieved context for direct keyword overlaps corresponding to the question's core entities and actions. Prioritize passages that explicitly connect these elements. Cross-reference multiple snippets to verify the precise terminology or phrase requested. Extract the exact wording from the text to form a concise final answer, relying solely on the provided context without adding external information or elaboration.
