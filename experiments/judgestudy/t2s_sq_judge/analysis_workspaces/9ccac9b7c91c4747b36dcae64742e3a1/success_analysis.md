# Success Memory Item 1
## Title
Multi-Constraint Entity Mapping
## Description
Decompose compound trivia prompts into discrete factual and linguistic parameters, then cross-reference each against retrieved documents to isolate the correct entity.
## Content
Break down the query into explicit identifiers (e.g., media title, performer, role, biographical timeline, and stylistic descriptors). Scan the knowledge base to locate a single subject that satisfies every condition simultaneously. Prioritize matches where all constraints converge, using the contextual evidence to confirm alignment before formatting the final response.
