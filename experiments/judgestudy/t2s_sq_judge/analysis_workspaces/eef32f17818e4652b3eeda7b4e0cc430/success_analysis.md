# Success Memory Item 1
## Title
Leverage Contextual Metadata and Tags
## Description
Extract target entities directly from structured metadata or tags present in retrieved snippets when they co-occur with query keywords.
## Content
When search results include categorical tags, labels, or related terms alongside the queried phrase or author, scan these metadata fields first. Explicit co-occurrence between the query elements and a candidate entity in the same snippet provides immediate resolution without requiring additional derivation.

# Success Memory Item 2
## Title
Anchor on Author-Quote Pairings
## Description
Use the combination of a distinctive opening line and credited author to narrow down potential titles or subjects before scanning for the final entity.
## Content
Literary and trivia questions often provide a unique quote paired with an author's name. Treat this pairing as a primary anchor to identify the specific work or theme. Once the work is identified, locate the requested attribute (e.g., character, setting, or inspiration) within the surrounding context or established associations mentioned in the snippets.

# Success Memory Item 3
## Title
Prioritize Direct Snippet Co-occurrence
## Description
Favor answers that appear in the same textual segment as the query's core identifiers, minimizing assumptions based on isolated facts.
## Content
In retrieval-augmented answering, trust explicit adjacency over implicit connections. If a candidate answer appears in close proximity to both the quoted text and the named author within a single document excerpt, accept it as the strongest signal. Avoid introducing external knowledge that contradicts or complicates the direct contextual link provided by the search engine.
