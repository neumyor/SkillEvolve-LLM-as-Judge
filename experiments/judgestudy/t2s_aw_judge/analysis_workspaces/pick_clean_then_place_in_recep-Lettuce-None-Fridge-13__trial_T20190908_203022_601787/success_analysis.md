# Success Memory Item 1
## Title
Systematic Search and Secure Acquisition
## Description
Prioritize high-probability storage locations to locate the target object, then immediately secure it via pickup to enable downstream processing.
## Content
When initiating a task requiring a specific object, scan common containers and surfaces in a logical sequence rather than random exploration. Once the object is visually confirmed, execute a direct pickup action to transition it into your inventory, establishing a stable baseline for subsequent manipulation steps.

# Success Memory Item 2
## Title
Sequential State Transformation Before Placement
## Description
Execute required object modifications strictly after acquisition and before final placement to satisfy conditional task constraints.
## Content
After securing the target object, navigate directly to the appropriate functional station designated for the required transformation. Perform the modification action while holding the object, verifying that the item reaches the correct state before proceeding to the final destination. This prevents premature placement and ensures task compliance.

# Success Memory Item 3
## Title
Destination Receptacle State Verification
## Description
Inspect the accessibility state of the target container upon arrival and modify it if necessary to prevent interaction failures during placement.
## Content
Upon reaching the destination location, always check whether the receptacle is open or closed. If the container is closed, execute an open action first. Only attempt the final move/place action once the container is fully accessible, ensuring a smooth completion of the task without wasted steps or errors.
