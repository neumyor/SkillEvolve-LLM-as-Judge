# Success Memory Item 1
## Title
Systematic Surface Exploration
## Description
Methodically check common storage and display surfaces in sequence when the target object is not immediately visible.
## Content
Upon entering a room, scan available furniture types (e.g., tables, shelves, drawers, stands). Navigate to each location sequentially, inspecting its contents via the environment feedback. Maintain a structured approach to cover all plausible hiding spots before concluding the search phase, avoiding premature termination or random movement.

# Success Memory Item 2
## Title
Closed Container Interaction Protocol
## Description
Always interact with closed storage units by opening them before assuming they are empty or moving on.
## Content
When arriving at a container that reports as closed, execute an `open` action first. Only after opening should you check the interior contents. If the target is absent, proceed to the next unexplored location rather than skipping potential hiding spots, as many objects are stored inside rather than displayed openly.

# Success Memory Item 3
## Title
Direct Acquisition and Placement Workflow
## Description
Once the target object is identified, immediately secure it and navigate to the final destination to complete the task.
## Content
After locating the target, use the `take [object] from [location]` command to add it to your inventory. Then, directly navigate to the specified destination using `go to [destination]`. Finally, execute the placement command (`move [object] to [destination]`) without unnecessary intermediate steps, backtracking, or re-verifying empty areas.
