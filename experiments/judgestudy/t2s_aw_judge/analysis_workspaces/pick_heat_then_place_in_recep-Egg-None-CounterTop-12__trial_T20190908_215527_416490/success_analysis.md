# Success Memory Item 1
## Title
Systematic Search & State Tracking
## Description
When the target object is not immediately visible, methodically check standard storage containers. Periodically verify possession status to prevent redundant searching and maintain accurate tracking of object locations.
## Content
Prioritize high-probability storage areas (refrigerators, cabinets, drawers, countertops) in a logical order. If initial searches yield nothing, expand to adjacent containers. Regularly execute the `inventory` command to confirm whether the target is already held or located elsewhere, which streamlines navigation and prevents wasted steps.

# Success Memory Item 2
## Title
Appliance Interaction & Heating Protocol
## Description
Interacting with heating appliances requires a precise sequence of placement, closure, and explicit heating commands. If direct heating fails or behaves unexpectedly, retrieve the item, verify its state, and apply the heating action while holding it at the appliance's location.
## Content
Approach the appliance and open it if closed. Place the item inside if required, then close the door. Attempt the `heat <item> with <appliance>` action. If the environment does not support internal heating or the action fails, take the item out, ensure you are carrying it, and execute `heat <item> with <appliance>` directly. Always confirm the heating action returns success before proceeding to the next sub-goal.

# Success Memory Item 3
## Title
Destination Navigation & Secure Placement
## Description
After completing the intermediate transformation, navigate directly to the specified receptacle. Verify possession one last time, then execute the placement command to finalize the task.
## Content
Maintain awareness of the final goal location throughout the process. Once the item is successfully modified, travel to the target countertop or receptacle. Briefly check `inventory` to confirm the heated item is still in hand, then use `move <item> to <receptacle>` to complete the objective. This ensures clean task termination without leaving objects unplaced or misplaced.
