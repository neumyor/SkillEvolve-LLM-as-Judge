# Success Memory Item 1
## Title
Systematic Environmental Search Protocol
## Description
When a target object is not immediately visible, employ a structured traversal of high-probability storage zones rather than random movement.
## Content
Prioritize checking refrigerators, cabinets, shelves, countertops, and drawers in a consistent order. Track visited locations to avoid redundant loops. If uncertainty arises about current holdings, verify with an inventory check before continuing the search. Maintain forward momentum toward the goal once the object is located.

# Success Memory Item 2
## Title
Sequential Phase Decomposition
## Description
Break multi-stage manipulation tasks into distinct, non-overlapping execution phases to preserve state integrity and prevent premature action attempts.
## Content
Phase 1: Locate and acquire the target object. Phase 2: Transport to the dedicated cleaning station and perform the cleaning interaction. Phase 3: Navigate to the final destination receptacle and complete the placement. Do not attempt cleaning or placement until the preceding phase is fully resolved and the agent is positioned correctly.

# Success Memory Item 3
## Title
Receptacle-Action Alignment Rule
## Description
Always synchronize navigation with environmental affordances, ensuring the agent arrives at the correct receptacle before issuing any interaction command.
## Content Map specific verbs to their required locations: use sinks exclusively for cleaning tasks, and tables/counters for placement. Never issue `clean`, `take`, or `move` commands while standing at an incompatible location. Verify arrival feedback confirms presence at the target receptacle before proceeding to the manipulation step.
