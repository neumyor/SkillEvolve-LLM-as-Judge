# Success Memory Item 1
## Title
Systematic Container Search
## Description
When locating a target object, methodically inspect available storage containers rather than relying on chance or random exploration.
## Content
Navigate to potential storage units (drawers, cabinets), open them if necessary, and check contents. If the target is absent, immediately proceed to the next logical container. Maintain a mental checklist of checked locations to avoid redundant searches and ensure efficient coverage of the environment.

# Success Memory Item 2
## Title
Phase-Based Task Execution
## Description
Decompose complex instructions into discrete operational phases and complete each phase at its required environmental location before advancing.
## Content
Identify the core sequence implied by the task (e.g., retrieve → process → deposit). Travel to the first relevant location, perform the initial action, then move to the next location for the subsequent step. Never attempt to process or place an object without first securing it in hand, and never leave a processing station until the action is confirmed complete.

# Success Memory Item 3
## Title
Pre-Interaction Location Verification
## Description
Always confirm spatial alignment with the environment before executing interaction commands to prevent invalid actions and wasted steps.
## Content
Before using verbs like `take`, `clean`, or `move`, verify that your current position matches the required affordance (e.g., inside a container for pickup, adjacent to a sink for washing, or at the target surface for placement). Adjust navigation immediately if misaligned, ensuring every interaction command targets a valid, accessible entity.
