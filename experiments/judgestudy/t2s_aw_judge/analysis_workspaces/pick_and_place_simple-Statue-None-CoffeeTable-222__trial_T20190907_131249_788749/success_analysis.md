# Success Memory Item 1
## Title
Methodical Container Scanning
## Description
When the target object is not immediately visible, systematically inspect available storage containers in sequence rather than relying on random exploration.
## Content
Navigate to each container in numerical or spatial order, open it to verify contents, and close it if empty. Track which containers have been checked to prevent redundant loops and maintain a tidy environment for subsequent searches.

# Success Memory Item 2
## Title
Adaptive Surface Expansion & State Verification
## Description
If initial storage areas yield no results, broaden the search to alternative surface types while periodically confirming possession status.
## Content
Use the `inventory` command at regular intervals to ensure the target hasn't already been picked up. Shift focus to common display surfaces (e.g., side tables, TV stands, shelves) that typically hold decorative items, ensuring comprehensive coverage without overlooking high-probability locations.

# Success Memory Item 3
## Title
Structured Pick-and-Place Execution
## Description
Once the target is located, follow a rigid three-step pipeline to complete the task without deviation.
## Content: First, execute `take [object] from [location]` to secure it. Second, navigate directly to the destination using `go to [target_surface]`. Third, finalize with `move [object] to [target_surface]`. Eliminate intermediate commands or detours between these steps to minimize step count and reduce error risk.
