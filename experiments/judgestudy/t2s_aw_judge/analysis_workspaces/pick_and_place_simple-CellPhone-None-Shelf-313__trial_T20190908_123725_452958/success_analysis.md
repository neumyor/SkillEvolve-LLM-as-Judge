# Success Memory Item 1
## Title
Systematic Location Scanning Protocol
## Description
Methodically traverse high-probability storage surfaces and containers to locate the target item, verifying each location's contents before advancing.
## Content
Prioritize common household surfaces (beds, desks, side tables) and enclosed storage (drawers, cabinets) during the search phase. Periodically check inventory to confirm possession status and avoid redundant searches. Only proceed to the next location after explicitly confirming the current one lacks the target.

# Success Memory Item 2
## Title
Proactive Container State Resolution
## Description
Always interact with closed storage units during the search phase rather than bypassing them, as targets are frequently stored inside.
## Content
When navigation leads to a closed drawer, cabinet, or box, execute an open action immediately. Inspect the interior contents upon opening. This prevents missing objects that are occluded or stored out of plain sight, ensuring thorough coverage of the environment.

# Success Memory Item 3
## Title
Decoupled Acquisition and Placement Workflow
## Description
Structure the task into two distinct operational phases: first secure the target object, then transport and place it at the destination.
## Content
Do not initiate placement actions until the target is explicitly confirmed in hand via an inventory check. Once acquired, navigate directly to the target container or surface and execute the move/place command. Maintaining strict phase separation prevents action interleaving errors and ensures reliable task completion.
