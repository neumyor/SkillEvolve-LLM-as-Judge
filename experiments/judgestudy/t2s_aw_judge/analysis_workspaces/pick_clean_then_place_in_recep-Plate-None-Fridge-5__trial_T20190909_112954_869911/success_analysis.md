# Success Memory Item 1
## Title
Sequential Storage Inspection
## Description
Systematically search common storage areas when the target object's location is unknown.
## Content
Iterate through available cabinets, drawers, and countertops in order. Discard empty or irrelevant containers immediately and advance to the next logical surface without lingering or repeating checks.

# Success Memory Item 2
## Title
Destination State Preparation
## Description
Verify and modify the receptacle's state before executing placement actions.
## Content
Upon arriving at a closed destination container, always perform an 'open' command first. Confirm the receptacle is accessible before attempting to move or place the held object to prevent invalid actions.

# Success Memory Item 3
## Title
Functional Station Routing
## Description
Directly navigate to environment-specific stations that fulfill intermediate task requirements.
## Content
Link cleaning operations to sinks/basins and storage operations to designated receptacles. Transition immediately to these functional stations after completing the prior step to maintain a linear, efficient workflow.
