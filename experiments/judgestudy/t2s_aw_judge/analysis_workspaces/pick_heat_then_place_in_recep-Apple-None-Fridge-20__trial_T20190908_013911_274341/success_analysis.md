# Success Memory Item 1
## Title
Systematic Surface Scanning and Inventory Transition
## Description
Prioritize locating the target object by methodically checking high-probability storage surfaces before initiating any manipulation or state-change actions.
## Content
Begin exploration by moving to common flat surfaces and containers where target items are statistically likely to spawn. Upon visual confirmation, execute a direct pickup action to transfer the object to your inventory. Verify the environment feedback confirms acquisition before advancing, ensuring you maintain control of the correct item throughout subsequent phases.

# Success Memory Item 2
## Title
Strict Open-Close Cycling for Enclosed Appliances
## Description
When interacting with closed appliances, enforce a deliberate open-place-close-retrieve sequence to guarantee proper state transitions and trigger internal processes.
## Content
Never attempt to place, remove, or manipulate items inside an appliance without first opening it. After positioning the object, close the appliance to initiate required background processes (e.g., heating, cooling). Reopen only when the process completes, then retrieve the object. This disciplined cycling prevents invalid interactions and ensures environmental state updates register correctly.

# Success Memory Item 3
## Atomic Sub-goal Decomposition with State Verification
## Description
Break compound multi-phase objectives into discrete, executable steps, confirming each state change via environment feedback before proceeding.
## Content
Decompose complex instructions (e.g., acquire-modify-store) into linear micro-tasks. After every action, parse the immediate feedback to validate success and update your current state (held items, appliance status, object properties). Advance to the next sub-goal only when the prior step is fully resolved, maintaining a clear execution chain without skipping prerequisite conditions.
