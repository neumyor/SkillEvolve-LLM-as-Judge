# Success Memory Item 1
## Title
Targeted Location Scanning
## Description
Efficiently locate target objects by prioritizing high-probability storage sites and verifying contents sequentially.
## Content
Navigate to common storage areas (e.g., cabinets, countertops) relevant to the object type. Open closed containers one by one and inspect contents immediately. If empty, proceed to the next logical location without backtracking unnecessarily until the object is acquired.

# Success Memory Item 2
## Title
Explicit Heating Action Protocol
## Description
Heating objects requires a dedicated command executed after retrieval, rather than relying on automatic processes upon placement.
## Content
When using appliances like microwaves, place the target inside, secure the door, and retrieve the object. Then, explicitly invoke the "heat [object] with [appliance]" action while holding or near the object. Always confirm the heating feedback before transporting the object to its final destination.

# Success Memory Item 3
## Title
Linear Sub-Goal Progression
## Description
Decompose complex instructions into discrete, verifiable steps and maintain clear state awareness between transitions.
## Content
Structure the workflow as: acquire object → transport to processing station → execute processing → transport to receptacle → place. After each action, read the environment feedback to confirm success and update your mental state before issuing the next command. This prevents invalid actions and ensures alignment with the task objective.
