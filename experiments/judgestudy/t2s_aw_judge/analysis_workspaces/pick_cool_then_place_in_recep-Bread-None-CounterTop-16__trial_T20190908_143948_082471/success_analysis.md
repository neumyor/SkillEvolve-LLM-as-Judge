# Success Memory Item 1
## Title
Systematic Container Inspection
## Description
Methodically search all available storage locations when the target object is not immediately visible.
## Content
Navigate to each container (cabinets, drawers, appliances, tables) in sequence. Open closed containers to verify contents before moving to the next location, ensuring thorough coverage without skipping potential hiding spots.

# Success Memory Item 2
## Title
Inventory State Verification
## Description
Confirm current possession status before initiating new search or manipulation steps.
## Content
Execute an `inventory` check periodically or when uncertain about object acquisition. This prevents redundant searching, validates successful pickups, and clarifies whether subsequent actions should focus on finding, holding, or placing the target item.

# Success Memory Item 3
## Title
Sequential Phase Execution
## Description
Decompose compound tasks into strict linear phases and complete each before advancing.
## Content
Structure multi-step goals (e.g., find → acquire → modify → transport → place) as independent checkpoints. Only proceed to the next phase once the current one is fully satisfied (e.g., object cooled before navigating to placement surface), maintaining clear state transitions and reducing logical errors.
