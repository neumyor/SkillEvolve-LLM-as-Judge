# Success Memory Item 1
## Title
Decouple Object Acquisition from Illumination Location
## Description
When the target object and required light source are not co-located, treat them as independent sub-goals: locate and retrieve the object first, then transport it to the lighting fixture.
## Content
Do not waste steps searching for an object that does not belong at the light source's location. Identify typical storage spots for the target object, navigate there, pick it up, and carry it to the designated lamp or light fixture to fulfill the spatial constraint.

# Success Memory Item 2
## Title
Activate Environmental Controls Before Inspection
## Description
Explicitly trigger the state change of the light source prior to attempting to view or examine objects within its range.
## Content
Tasks specifying "under the light" or similar conditions often require the environment to be in an active state. Use the interaction command to turn on the lamp early in the sequence to guarantee proper visibility and prevent inspection failures caused by unmet environmental prerequisites.

# Success Memory Item 3
## Apply Semantic Location Heuristics with Targeted Backtracking
## Description
Use real-world object placement priors to redirect searches when initial locations yield nothing, then immediately return to the primary objective site.
## Content
If an object is absent from the expected location, pivot to semantically appropriate alternatives (e.g., beds for pillows, counters for kitchenware). Once acquired, abandon further exploration and backtrack directly to the original target location rather than continuing random searches.
