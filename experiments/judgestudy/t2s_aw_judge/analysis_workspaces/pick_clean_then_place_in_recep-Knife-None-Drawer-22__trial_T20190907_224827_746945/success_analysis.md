# Success Memory Item 1
## Title
Systematic Object Search with Fallback
## Description
When the target object is not found in the initially assumed storage location, transition to high-probability alternative surfaces rather than repeating searches.
## Content
Prioritize checking drawers and cabinets first; if empty, proceed to countertops or tables where loose items are commonly placed. Maintain a mental map of visited locations to avoid redundant checks and efficiently locate the object.

# Success Memory Item 2
## Title
Strict Phase Adherence for Multi-Step Tasks
## Description
Decompose compound tasks into discrete, ordered phases (acquire → process → deposit) and execute each phase completely before transitioning to the next.
## Content
Verify object pickup before moving to cleaning stations. Confirm cleaning completion before navigating to the final receptacle. Avoid interleaving actions across phases to prevent state confusion or invalid commands, ensuring smooth progression through the task pipeline.

# Success Memory Item 3
## Title
Pre-Placement Receptacle Verification
## Description
Always verify and adjust the state of the target receptacle immediately before attempting to place an item inside.
## Content
Navigate to the destination receptacle, check its current state, and open it if closed. Only proceed with the placement action once the receptacle is confirmed accessible, ensuring successful deposition without extra steps or failed interactions.
