# Success Memory Item 1
## Title
Systematic Storage Scanning with Inventory Verification
## Description
Efficiently locate target objects by prioritizing common storage containers while periodically verifying current holdings to guide search decisions.
## Content
When searching for an item, traverse high-probability storage locations (e.g., drawers, shelves, countertops) rather than assuming immediate availability. Before committing to a new area, check your inventory to confirm what you are carrying and whether the item has already been acquired. Use negative feedback from empty containers to prune the search space and prioritize unexplored or closed storage units.

# Success Memory Item 2
## Title
State-Aware Container Interaction Protocol
## Description
Ensure reliable access to stored items by explicitly managing container states before inspection.
## Content
Upon arriving at any potential storage location, first assess its open/closed status. If a container is closed, execute an open action immediately before attempting to view or retrieve contents. This prevents failed observation attempts and guarantees that all internal items become accessible for selection. Always pair container opening with subsequent inspection or pickup actions.

# Success Memory Item 3
## Title
Linear Acquisition-to-Placement Execution
## Description
Streamline task completion by following a strict sequence once the target is located.
## Content
After identifying the target object, immediately execute a take/pick action to secure it in hand. Navigate directly to the designated destination without intermediate stops. Finally, perform a move/place action to transfer the item to the target surface or fixture. Maintain this linear flow post-acquisition to minimize step count and avoid task abandonment.
