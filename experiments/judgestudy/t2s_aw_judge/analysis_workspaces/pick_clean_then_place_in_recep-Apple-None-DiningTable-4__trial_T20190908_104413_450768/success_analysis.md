# Success Memory Item 1
## Title
Sequential Sub-Goal Execution
## Description
Decompose compound objectives into a strict, prerequisite-dependent linear pipeline.
## Content
Map the high-level goal to discrete operational phases (acquisition, processing, deposition). Complete each phase entirely before initiating the next, ensuring that state changes from prior steps (e.g., acquiring an item, altering its condition) are fully realized and acknowledged before transitioning to subsequent movements or interactions.

# Success Memory Item 2
## Title
Affordance-Driven Location Routing
## Description
Direct navigation and interactions based on functional environmental properties rather than fixed object labels.
## Content
Identify destinations that natively support the current operation (e.g., storage containers for retrieval, washing stations for cleaning, flat surfaces for placement). Always verify interactive states (open/closed, accessible/blocked) upon arrival before attempting manipulation, allowing the plan to adapt dynamically to real-time environmental feedback.

# Success Memory Item 3
## Title
Inventory & Attribute Verification Loop
## Description
Continuously cross-reference held items and their properties against task constraints before committing to actions.
## Content
Maintain explicit tracking of possession and object attributes throughout execution. Prior to any placement or major transition, confirm that all intermediate requirements (e.g., correct object identity, required cleanliness level) are satisfied. Use immediate post-action feedback to validate state transitions and adjust routing if prerequisites remain unmet.
