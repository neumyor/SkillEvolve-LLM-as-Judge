# Success Memory Item 1
## Title
Sequential Subgoal Decomposition
## Description
Break complex multi-step objectives into a linear chain of atomic operations: locate, acquire, process, and deliver.
## Content
Structure the workflow as Find → Pick → Transform → Place. Execute each step sequentially, verifying environmental feedback confirms completion before transitioning to the next phase. This prevents state confusion, ensures prerequisites are met, and maintains clear progress tracking throughout the episode.

# Success Memory Item 2
## Title
Explicit State Management for Containers and Appliances
## Description
Always navigate to a container or appliance before interaction, and explicitly manage its open/closed state prior to accessing contents or initiating operations.
## Content
When targeting a storage unit or tool, first travel to its location. Check its current state; if closed, issue an open command and wait for confirmation before attempting to retrieve items or perform tasks. This guarantees valid interactions, avoids invalid action penalties, and aligns agent state with the environment's physical constraints.

# Success Memory Item 3
## Title
Destination Verification and High-Level Action Utilization
## Description
Prioritize direct, environment-supported commands to streamline execution, and always navigate to the target receptacle before final placement.
## Content
Leverage concise, task-specific actions (e.g., heat, move) when available to reduce unnecessary intermediate steps. Before placing an object, travel to the designated surface or receptacle to ensure proximity, confirm destination readiness, and trigger placement options. This minimizes backtracking and ensures successful delivery upon task completion.
