# Success Memory Item 1
## Title
Prioritize Functional Furniture Heuristics for Paired Targets
## Description
When a task requires interacting with two related objects (e.g., a target item and its illumination source), navigate to furniture types historically associated with housing both items rather than searching randomly.
## Content
Identify the functional relationship between task objects (e.g., decorative items and lamps frequently share flat surfaces like dressers, nightstands, or desks). Use this semantic link to predict a single high-probability location, allowing simultaneous discovery of all required entities and minimizing navigation steps.

# Success Memory Item 2
## Title
Activate Environmental Preconditions Before Inspection
## Description
For tasks demanding observation under a specific state (e.g., lit, heated, wet), execute the state-changing action on the source object while positioned at the target location before attempting examination.
## Content
Sequence actions so that enabling devices are turned on or activated prior to or immediately upon reaching the target. This guarantees the required environmental condition is active during the inspection phase, preventing failed examination attempts caused by unmet prerequisites.

# Success Memory Item 3
## Title
Escalate to Grasp Actions When Direct Examination Is Insufficient
## Description
If proximity-based examination commands fail to satisfy observational constraints or yield no progress, transition to pickup/grasp actions to achieve a closer, more definitive interaction.
## Content: Treat "look at" or "examine" objectives as flexible interaction goals rather than rigid command sequences. When static inspection does not trigger task completion or the environment limits detailed viewing, use `take` or `pick up` to manipulate the target directly, which typically fulfills observational requirements in constrained text-based worlds.
