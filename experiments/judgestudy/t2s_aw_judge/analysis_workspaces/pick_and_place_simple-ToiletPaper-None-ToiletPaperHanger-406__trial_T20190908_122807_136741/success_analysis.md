# Success Memory Item 1
## Title
Contextual Search Fallback Protocol
## Description
Prioritize systematic inspection of storage containers before shifting to contextually relevant surfaces when searching for misplaced objects.
## Content
Begin searches by targeting enclosed storage units (e.g., cabinets, drawers) and open them to verify contents. If these locations do not yield the target, immediately pivot to fixtures or surfaces that semantically match the object's typical placement (e.g., checking bathroom fixtures for bathroom supplies). This prevents redundant searching and accelerates target acquisition.

# Success Memory Item 2
## Title
Strict Acquisition-to-Placement Pipeline
## Description
Execute a linear workflow that separates object acquisition from destination navigation to prevent state conflicts.
## Content
Never attempt to place an object without first securing it in inventory using a direct 'take' command. After acquisition, navigate exclusively to the target receptacle before executing the final placement action. This separation ensures the agent maintains proper state tracking and avoids invalid interactions caused by holding multiple items or misaligning positions.

# Success Memory Item 3
## Feedback-Grounded State Verification
## Description
Treat every environmental response as a mandatory checkpoint to validate action outcomes and dictate subsequent moves.
## Content
After each movement or interaction, parse the system feedback to confirm physical state changes (e.g., container status, item presence, inventory updates). Use this verified data to either advance to the next planned step or dynamically reroute the search path. Relying on real-time feedback rather than assumptions eliminates wasted actions and maintains trajectory efficiency.
