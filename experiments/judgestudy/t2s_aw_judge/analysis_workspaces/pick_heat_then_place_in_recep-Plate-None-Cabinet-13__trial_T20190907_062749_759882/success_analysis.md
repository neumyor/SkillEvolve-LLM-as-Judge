# Success Memory Item 1
## Title
Systematic Location Scanning
## Description
Efficiently locate target objects by prioritizing high-probability storage areas when initial checks yield nothing.
## Content
When the target item is not in inventory or immediate view, sequentially inspect common storage containers (drawers, cabinets) and work surfaces (countertops). Verify contents upon arrival before navigating away to prevent redundant backtracking. Maintain a clear mental map of checked locations to focus subsequent searches on unexplored, high-yield areas.

# Success Memory Item 2
## Title
Standardized Appliance Interaction Cycle
## Description
Execute a consistent open-place-close-retrieve-heat sequence to successfully interact with heating devices.
## Content
For tasks requiring thermal processing, follow a strict state-transition workflow: open the appliance door, move the item inside, close the door, reopen it, retrieve the item, perform the explicit heating action, and finally close the appliance. This accounts for environment mechanics where heating commands require the item to be physically placed and retrieved, ensuring proper state synchronization before proceeding.

# Success Memory Item 3
## Direct Receptacle Transfer
## Description
Navigate directly to a valid destination container and execute a single transfer action to complete the task.
## Content
Once the intermediate processing step is finished, travel straight to any available receptacle matching the task requirement. While holding the processed item, use the direct transfer command (`move [item] to [receptacle]`) to finalize the objective. Avoid unnecessary intermediate placements or inspections once the target container is identified and accessible.
