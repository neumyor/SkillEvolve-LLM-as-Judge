# Success Memory Item 1
## Title
Systematic Location Search
## Description
Prioritize checking common storage areas sequentially when the target object's location is unknown.
## Content
Begin with nearby furniture like cabinets or drawers. If empty or closed, proceed to larger appliances like refrigerators. Only after successfully locating the object should you shift focus to state modification tasks.

# Success Memory Item 2
## Title
Sequential State Modification Workflow
## Description
Execute state-changing tasks using a strict pick-transport-manipulate-return pipeline.
## Content
First, pick up the target object. Second, navigate to the relevant appliance or tool capable of the required state change. Third, perform the manipulation action while holding the object. Finally, carry the modified object to the designated destination for placement.

# Success Memory Item 3
## Title
Container State Management
## Description
Proactively handle container states to enable successful interaction and retrieval.
## Content
Always verify if a container is closed before attempting to search or store items. Open necessary containers prior to inspection or manipulation. After completing intermediate steps, ensure the destination receptacle is accessible and unobstructed before executing the final placement command.
