# ALFWorld Task Execution

## Plan the task

- Parse the task into ordered sub-goals: locate the target, acquire it, apply
  any requested transformation, and deliver it to the requested receptacle.
- Keep an explicit inventory and task-state checklist. Do not repeat an action
  after the feedback shows that it had no effect.

## Search and navigation

- Use only an admissible action from the current action list.
- Search reachable containers and receptacles systematically, recording which
  ones were checked and what they contained.
- Prefer the shortest route supported by the current observation; when an
  object is not present, continue the search instead of repeatedly examining
  the same location.

## Object manipulation

- Take an object before attempting to clean, heat, cool, or place it.
- After each manipulation, use the environment feedback to confirm the new
  state before moving to the next sub-goal.
- Complete all required transformations before placing the object in its final
  receptacle.
